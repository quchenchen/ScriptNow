## 二、核心架构亮点

### 2.1 Story System（合同驱动体系）

```
MASTER_SETTING.json + 卷合同 + 章节合同
    → accepted CHAPTER_COMMIT（事实入账）
        → state.json（运行时状态）
        → index.db（结构化历史）
        → summaries/（章节摘要）
        → memory_scratchpad.json（长期语义记忆）
        → vectors.db（向量索引）
```

**核心理念**：写前有合同，写后有提交，状态是派生视图，不是手工维护的垃圾堆。

### 2.2 Agent 三剑客

| Agent | 职责 | 时机 |
|-------|------|------|
| Context Agent | 五段写作任务书：委托→故事→人物→写法→收尾 | 写前 |
| Reviewer | 五维审查：设定/时间线/叙事连贯/角色/逻辑 | 写后 |
| Data Agent | 事实提取 + 实体消歧 | 提交前 |

### 2.3 防幻觉三定律

1. **大纲即法律** — 不得擅自发挥
2. **设定即物理** — 能力 ≤ index.db 记录
3. **发明需识别** — 新实体由 Data Agent 提取入库

### 2.4 追读力系统

- **Hook**：危机钩 / 悬念钩 / 渴望钩 / 情绪钩 / 选择钩
- **Cool-point**：装逼 / 反杀 / 揭秘
- **微兑现**：每章至少一个可感知的进度推进
- **债务追踪**：承诺与兑现的闭环

### 2.5 三层记忆

| 层级 | 内容 | 存储 |
|------|------|------|
| Working | 本章章纲 + 近期摘要 + 主角状态 | 运行时拼装 |
| Episodic | 近期状态变化 + 关系变化 + 出场记录 | index.db |
| Semantic | 角色状态 / 故事事实 / 世界规则 / 时间线 / 开放伏笔 / 读者承诺 / 关系 | memory_scratchpad.json |

每条记忆含 `status` 字段：active / outdated / contradicted / tentative

### 2.6 写作铁律 (core-constraints.md)

| 层级 | 约束 |
|------|------|
| **Hard** | 每章有推进、上章钩子要回应、禁止占位正文 |
| **Soft** | 前 200-400 字入戏、章末保留未闭合问题、800-1400 字一个脉冲 |
| **Style** | 对话带意图、避免大段纯解释、避免机械收尾 |
| **Anti-AI** | 禁止连续 3 段同句式、情绪通过行为描写、每 500 字节奏变化、章末禁止安全着陆 |

### 2.7 Strand Weave 节奏

| 线程 | 占比 | 连续上限 | 断档上限 |
|------|------|----------|----------|
| Quest（主线） | 60% | 5 章 | — |
| Fire（感情线） | 20% | — | 10 章 |
| Constellation（世界观） | 20% | — | 15 章 |

## 三、与 ScriptNow 架构对照

| webnovel-writer | ScriptNow 对应物 | 差距 |
|-----------------|------------------|------|
| MASTER_SETTING.json | 蓝图 (NovelBlueprintModel) | 蓝图有锚点/角色/弧线/事件，但缺"合同"语义 |
| CHAPTER_COMMIT | NovelDocumentRevisionModel | 有版本号，但缺事件提取/投影链 |
| Context Agent | Writer._context() | 有上下文注入，但缺少"任务书"五段结构 |
| Reviewer | NovelQualityPanel + Reviewer Agent | 有审查维度但缺 block/硬约束 |
| Data Agent | narrative_extractor.py | 有出口笔记提取，但缺实体消歧 |
| 追读力系统 | 叙事状态机 (narrative_state.py) | 有钩子/特质，缺 Cool-point/微兑现/债务 |
| 三层记忆 | writer_context.py 上下文预计算 | 缺语义记忆持久化层 |
| Strand Weave | 无 | 完全缺失 |
| Anti-AI 规则 | 无 | 完全缺失 |
| Dashboard | NarrativeGraphPanel.vue | 有图谱，缺追读力面板 |
| 题材模板 | WizardPage 类型选择 | 有类型但无题材级模板 |
| 章节提交链 | api.py adopt endpoint | 缺多路投影驱动 |

## 四、三档融合建议

### 🟢 Quick Wins（2-4 小时/项）

1. **写作铁律注入** — 移植 core-constraints.md 的 Hard/Soft/Anti-AI 规则到 Writer prompt
2. **五段任务书** — Context Agent 输出格式改造为 委托→故事→人物→写法→收尾
3. **Block review** — 审查加 blocking/non-blocking 分类
4. **伏笔分类** — 叙事状态机加入 hook 类型枚举（危机/悬念/渴望/情绪/选择）
5. **章末检测** — 自动检测"安全着陆"并警告

### 🟡 Medium（1-3 天/项）

6. **章节提交链** — 采纳时驱动多路投影（状态/索引/摘要/记忆）
7. **语义记忆层** — 移植 memory_scratchpad.json 分桶 + 状态降级
8. **Strand Weave** — 节奏监控面板
9. **Dashboard 追读力** — React 面板或 Vue 复刻
10. **Anti-AI 检测** — 章节审查加句式/节奏/AI 味扫描

### 🔵 Horizon（1-2 周/项）

11. **Story System 化** — 蓝图升级为 MASTER_SETTING 语义
12. **题材模板库** — 37 个网文模板 → ScriptNow 通用模板
13. **追读力完整系统** — Cool-point + 微兑现 + 债务追踪
14. **事件审计链** — CHAPTER_COMMIT + 事件审计
15. **项目学习 (/learn)** — 作者风格累积与注入
