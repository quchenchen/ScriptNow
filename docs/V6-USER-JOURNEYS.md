# ScriptFlow V6 用户旅程与低保真线框

- **Status**: Accepted for implementation
- **Date**: 2026-07-16
- **Depends on**: [`PRD-V6.md`](./PRD-V6.md)、ADR-0004、ADR-0005

## 共同入口：用户先选择目标

Dashboard 的“新建项目”直接呈现四个任务：创作一部小说、创作一个剧本、把作品改编成小说、把作品改编成剧本。选择任务后再询问创作成熟度、目标受众、题材和风格。改编项目要求上传 Source Canon 并确认使用权；原创项目接受主题、一句话灵感、梗概或大纲。

```text
┌──────────────────────────────────────────────────────────────┐
│ 你今天想创作什么？                                           │
│ [创作一部小说]             [创作一个剧本]                    │
│ [把作品改编成小说]         [把作品改编成剧本]                │
└──────────────────────────────────────────────────────────────┘
```

## 共同工作台

```text
┌─────────────────────────────────────────────────────────────────┐
│ 项目   [专注创作] [故事规划] [审阅决策]       保存 · 决策收件箱 │
├────────────────┬────────────────────────────────────────────────┤
│ 当前模式的目录 │ 当前作品对象                                  │
│ / 问题分组     │ 正文 / 上下游透镜 / 证据与 Revision Compare   │
└────────────────┴────────────────────────────────────────────────┘
                    Agent Task 仅在相关时以可收起状态出现
```

默认进入“专注创作”。用户不是在三个割裂页面间跳转，而是在同一作品对象上切换写作、理解和决策三种心智模式。Growth Tree 默认只显示当前对象的上下游；完整探索是二级入口。

## Journey A：原创剧本

用户选择“创作一个剧本”，输入种子；创意总监交付候选，用户采用、编辑或创建 Branch；编剧架构师形成 Story Core 与 Story Beat；用户指定本轮写作范围；撰写师创建 Scene，用户直接编辑 Action/Dialogue；审稿人运行 Ralph Loop，用户按 diff 处理问题并导出 DOCX。

```text
作品目录                    Scene Editor                 Agent Team
EP01  草稿                  【场景1】地点·时间           撰写师：已交付
  S1  待审                  △ 动作                      审稿人：72 分
  S2  dirty                 角色：对白                  [查看问题与 diff]
```

必须覆盖候选未选择、Branch 未采用、生成中可取消、生成失败可重试、保存失败可恢复、Ralph human review 和 Cascade dirty 等状态。

## Journey B：小说改编剧本

用户确认使用权并上传小说；系统展示解析进度和章节目录；用户选择忠实、平衡或自由策略；改编策划师生成 Adaptation Map；用户确认保留、合并、删除、重排和原创新增；Story Core、Story Beat 与 Scene 保留 Source Reference；审稿人检查人物偏移、情节遗漏、来源冲突和媒介转换质量。

```text
原著章节             Adaptation Map              改编结果
第 1 章  已解析       保留 → Beat 01             EP01 / Scene 1
第 2–3 章 已解析      合并 → Beat 02             来源：第 2–3 章
第 4 章  有警告       删除（节奏原因）           [查看原文]
```

上传、解析、索引分别显示进度；单章失败不阻断全部项目；无来源 Scene 标注“原创新增”；Source Canon 更新后显示失效引用。

## Journey C：原创小说（基础）

用户建立 Story Core 和章节大纲，在 Chapter Editor 中持续写作、自动保存和创建 Revision。工作台使用 Volume、Chapter、POV，不出现 EP、剧本纸或 Seedance 主操作。

## Journey D：改编小说（基础）

该路径复用 Source Canon 和 Adaptation Map，以 Chapter 为交付单位。新 Chapter 可回看来源章节，并标记忠实改写、视角转换、合并或原创新增。

## 导航与交互规则

- URL 包含 project、一级区域和当前正文单位；刷新后回到同一位置。
- 一级区域切换不改变当前采用 Revision。
- 从来源、dirty badge 或审查 issue 跳转后可返回原位置。
- 图标按钮、卡片、弹窗和表单支持键盘及可访问性要求。
