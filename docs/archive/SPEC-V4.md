## 一、产品概要

### 1.1 一句话定位

**AI Agent 驱动的短剧剧本全生命周期创作平台。** 用户输入创意 → Agent 团队自主推进 7 个阶段 → 输出剧本 + 制作资产包。

### 1.2 核心差异化（vs StoryPlay）

| StoryPlay | ScriptFlow |
|-----------|-----------|
| 用户手动点击 AI 按钮 | Agent 团队自主推进，用户审核决策 |
| 一次性 AI 评估 | Ralph Loop 循环审核（≤3次） |
| 无记忆 | 三层隔离记忆（全局/项目/会话） |
| 无协作 | 多人实时协作 |
| 无全球化 | 翻译 + 文化适配 |

## 二、用户画像与核心旅程

### 2.1 用户画像

| 角色 | 场景 | 核心任务 | 频次 |
|------|------|---------|------|
| **独立编剧** | 从零创作短剧 | 灵感→架构→撰写→导出 | 2-3部/月 |
| **编剧工作室** | 团队协作量产 | 分工撰写+统一风格+质量把控 | 10-20部/月 |
| **MCN/平台** | 批量采购评估 | 上传剧本→评估→筛选 | 50+部/月 |
| **网文作者** | 小说改编短剧 | 上传小说→改编策略→转化 | 1-2部/月 |

### 2.2 核心用户旅程（独立编剧）

```
┌─────────────────────────────────────────────────────────────┐
│ J1: 注册登录 (30秒)                                          │
│ 输入手机号 → 获取验证码 → 登录 → 自动赠送1天会员+100剧点       │
├─────────────────────────────────────────────────────────────┤
│ J2: 创建项目 (1分钟)                                         │
│ 点击"新建项目" → 选择类型(原创) → 填写标题+受众+题材           │
│ → 项目创建 → 自动进入灵感孵化                                 │
├─────────────────────────────────────────────────────────────┤
│ J3: 灵感孵化 (1-2分钟)                                       │
│ Agent 消息："为你设计了3个方案"                               │
│ 用户查看方案卡片 → 选择方案A → Agent 确认                     │
│ → 阶段推进到故事架构                                         │
├─────────────────────────────────────────────────────────────┤
│ J4: 故事架构 (2-3分钟)                                       │
│ Agent 产出：标题·梗概·10角色·80集大纲·爽点分布图              │
│ ReviewAgent 自动评分 85 → 通过                                │
│ 用户查看角色卡片和大纲 → 点击"确认，进入撰写"                  │
├─────────────────────────────────────────────────────────────┤
│ J5: 剧本撰写 (5-10分钟，80集)                                │
│ Agent 逐集撰写，表格实时更新                                  │
│ 用户可随时：查看任意集详情 / 修改 / 通过 / 批量导出            │
│ Ralph Loop：第5集评分72 → 自动修改 → 84分通过                 │
│ 80集全部完成 → 自动进入质量审核                                │
├─────────────────────────────────────────────────────────────┤
│ J6: 质量审核 (1分钟)                                          │
│ Agent 展示六维雷达图 + 问题列表                                │
│ 综合评分 85 → 通过 ✅ → 进入润色                               │
├─────────────────────────────────────────────────────────────┤
│ J7: 润色 (1分钟)                                              │
│ Agent 自动优化对白/节奏/格式                                   │
│ 用户确认 → 进入资产提取                                        │
├─────────────────────────────────────────────────────────────┤
│ J8: 资产提取 (30秒)                                           │
│ Agent 自动提取：10角色·6场景·5道具·连续性台账                  │
├─────────────────────────────────────────────────────────────┤
│ J9: 提示词生成 (1分钟)                                        │
│ Agent 生成5个关键场景的 Seedance 2.0 提示词                    │
├─────────────────────────────────────────────────────────────┤
│ J10: 导出                                                    │
│ 用户选择：剧本(.docx) / 资产包(.json) / 提示词(.json) / 全部   │
│ → 打包下载                                                   │
└─────────────────────────────────────────────────────────────┘
总耗时：约 12-20 分钟完成一部 80 集短剧全流程
```

### 2.3 改编用户旅程（网文作者）

```
上传小说(.txt/.docx) → Agent 预分析(章节/角色/情节线)
  → AdaptationStrategyAgent 决策(保留/删减/合并/新增)
  → 用户确认策略 → 进入标准7阶段流程(从阶段2故事架构开始)
```

## 六、设计系统

### 6.1 设计原则

| 原则 | 说明 |
|------|------|
| **暗色原生** | `#08090a` 根背景，内容从暗色中浮现，非"暗色模式套在亮色设计上" |
| **密度优先** | 操作界面（Operate surface），信息密度高，操作可见性强 |
| **紫色唯一色** | `#7170ff` 仅用于交互元素和强调，其余全灰阶 |
| **边框即层级** | 半透明白色边框 (`rgba(255,255,255,0.05~0.08)`) 替代阴影 |
| **Inter 510 权重** | 510 是默认强调权重（介于 Regular 400 和 Medium 500 之间） |

### 6.2 色彩令牌

```css
--bg-root:    #08090a   /* 最深背景 */
--bg-panel:   #0f1011   /* 面板背景 */
--bg-surface: #191a1b   /* 卡片/表面 */
--bg-elevated:#28282c   /* 悬浮/hover */
--t1:         #f7f8f8   /* 主文字 */
--t2:         #d0d6e0   /* 次文字 */
--t3:         #8a8f98   /* 辅助文字 */
--t4:         #62666d   /* 最弱文字 */
--accent:     #7170ff   /* 强调色(交互) */
--accent-bg:  #5e6ad2   /* 强调色(背景) */
--green:      #27a644   /* 成功/完成 */
--amber:      #eab308   /* 警告/修改中 */
--red:        #ef4444   /* 错误/失败 */
--bs: rgba(255,255,255,0.05)  /* 细边框 */
--bw: rgba(255,255,255,0.08)  /* 标准边框 */
```

## 八、MVP 定义

### 8.1 MVP 范围（P0）

```
交付物：
  ✅ 登录/注册（手机号+验证码）
  ✅ 项目列表 + 创建
  ✅ 项目工作台（7阶段完整流程）
  ✅ 灵感孵化（3方案生成+选择）
  ✅ 故事架构（大纲+角色+爽点图）
  ✅ 剧本撰写（80集表格+详情+修改+批量导出）
  ✅ Ralph Loop（自动审核+自动修改≤3次）
  ✅ Agent Chat（滑入式，可调宽）
  
不包含（V1.0+）：
  ❌ 六维雷达图（阶段4-5-6-7合并为简单卡片展示）
  ❌ 网文改编
  ❌ 多人协作
  ❌ 全球化
  ❌ 会员/剧点系统（硬编码免费体验）
```

### 8.2 MVP 成功指标

| 指标 | 目标 |
|------|------|
| 用户从创意到80集成稿 | ≤ 20 分钟 |
| Agent 审核通过率（1次通过） | ≥ 60% |
| Ralph Loop 平均重试次数 | ≤ 1.5 次 |
| 用户手动修改率 | ≤ 30% 剧集 |
| 页面零 JS 错误 | 100% |

### 8.3 技术栈确认

```
前端:   Vue 3 + Vite              (与 StoryPlay/Toonflow 一致)
Agent:  AgentScope 2.0            (阿里达摩院，原生 DashScope + Multi-tenancy + Agent Team)
LLM:    DashScope (deepseek-v4-pro / qwen3.7)
后端:   FastAPI                    (与 MuMuAINovel/Digital Studio 一致)
数据库: SQLite (MVP) → PostgreSQL
存储:   AliOSS (剧本文件)
通信:   AgentScope Event System (SSE)
设计:   暗色 Linear 风格 (以上令牌)
```
