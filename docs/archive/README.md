# 非现行资料归档

本目录保存仍有追溯价值、但不再构成 ScriptNow 当前产品基线的资料。

## 使用规则

- 当前需求和验收只以 `docs/v7-spec-v1.1/` 为准。
- 归档内容不得被生产代码、测试 fixture 或构建脚本直接导入。
- 从归档复用任何设计或实现前，必须完成契约对照和 characterization test。
- 用户上传素材、数据库、密钥和运行日志不进入本目录，也不进入 Git。

## 批次

### 2026-07-29

- `research-analysis/`：阶段性 API、架构、修复和圆桌分析网页。
- `fusion-research/`：外部项目融合调研原稿；结论已由现行 `09`、`10` 规格吸收。
- `implementation-audits/`：旧清理报告、小说 Skill 审计、UI/MCP 检查记录和截图。

恢复方式：所有文件仍由 Git 跟踪，可从历史提交或本目录读取；它们只是不再出现在现行
规格和可执行应用目录中。
