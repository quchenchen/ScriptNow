P0 StoryMap 空卷生成

方案

后端在 StoryMap 生成前检查 creation_settings，值缺失时使用默认参数，不静默生成空卷。

# api.py — NovelStoryMapGenerator.generate() 入口处
if not (project.direction.get("volume_one") and project.direction.get("volume_two")):
    raise HTTPException(400, "请先设置卷数和每卷章节数")

# 或更温和的方式：补默认值
direction["volume_one"] = direction.get("volume_one") or "1"
direction["volume_two"] = direction.get("volume_two") or "3"
direction["chapter_target_words"] = direction.get("chapter_target_words") or "2000"
文件改动量风险
api.py StoryMap generate 入口+5行低

P0 蓝图采纳 409

方案

Blueprint 候选在生成完成到客户端采纳之间有竞态。加一个重试缓冲或检查候选的实际状态。

# api.py — adopt endpoint
candidate = await session.get(BlueprintCandidate, candidate_id)
if candidate is None:
    # 重新查询最新候选（可能 ID 已变更）
    candidate = (await session.scalars(
        select(BlueprintCandidate)
        .where(BlueprintCandidate.project_id == project_id)
        .order_by(BlueprintCandidate.created_at.desc()).limit(1)
    )).one_or_none()
    if candidate is None:
        raise HTTPException(409, "...")
文件改动量风险
api.py adopt_blueprint 端点+8行中（可能引入不一致行为）

P1 API 超时但后台成功

方案

所有生成类端点改为异步模式：POST 立即返回 run_id，客户端通过 GET /runs/{run_id} 轮询状态。不改变已有 API 签名，加新端点。

# 新端点
GET /projects/{id}/runs/{run_id} → {"status":"running|succeeded|failed", "result":...}

# 现有端点保持兼容（阻塞模式），加 query param 支持异步
POST /.../generate?async=true → {"run_id":"xxx", "status":"accepted"}
文件改动量风险
api.py + agent_runtime.py~40行中

P1 字段类型强制 string

方案

project.direction 中的数值字段接受 int 并自动转为 string。在 create_project 入口处做标准化。

# api.py — create_project
direction = body.direction or {}
for key in ("volume_one", "volume_two", "chapter_target_words", "target_length"):
    if key in direction and not isinstance(direction[key], str):
        direction[key] = str(direction[key])
文件改动量风险
api.py create_project+4行极低

P1 DeepSeek 并发争抢

方案

在 billing.py 或 AgentRuntime 中添加单 Provider 并发限制（如 max_concurrent=2），超出时排队。不阻塞不同 Provider 的请求。

# agent_runtime.py
import asyncio
_provider_semaphores: dict[str, asyncio.Semaphore] = {}

async def _acquire_provider_slot(provider: str):
    sem = _provider_semaphores.setdefault(provider, asyncio.Semaphore(2))
    await sem.acquire()
    return sem
文件改动量风险
billing.py 或 agent_runtime.py~15行中
