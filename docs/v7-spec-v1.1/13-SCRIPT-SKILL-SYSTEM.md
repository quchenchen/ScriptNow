# ScriptNow 剧本技能体系 v1

> 状态：已实现并纳入运行时准入
> 适用域：`script`，不得被 `novel` 正文、StoryMap、Writer、审读或导出模块复用

## 1. 结论

原有剧本技能只有角色级薄提示，能够被 AgentScope 发现，但不足以稳定支撑真实剧本创作：

- 开发阶段缺少“戏剧引擎、场景引擎、银幕身份”的可验证标准；
- 蓝图与 StoryMap 没有明确区分，场景因果和集级推进规则过薄；
- 写作技能虽强调可拍摄性，但缺少写前状态、场景转折和连续性契约；
- 审读缺少证据锚点、严重度与事实/技法/偏好/制作风险分层；
- 中国剧本格式与好莱坞格式存在于代码校验中，却没有作为可路由技能进入 Agent 上下文；
- 剧本域没有技能准入注册，无法阻止未验证技能自动挂载。

本轮将体系重建为“创作判断 → 结构组织 → 场景生产 → 质量审读 → 格式投影”五层。格式是最后一层，不以格式模板替代剧本思维。

## 2. 运行时分层

| 阶段 | 角色 | 核心技能 | 条件技能 | 主要产物 |
|---|---|---|---|---|
| 创意发散 | 灵感导演 | `script-develop` | 无 | 可比较的剧本方向候选 |
| 蓝图规划 | 故事建筑师 | `script-storymap` | `script-structure-planning` | 蓝图候选、因果 StoryMap |
| 逐场写作 | 主笔 | `script-write` | `script-format-chinese` 或 `script-format-hollywood` | 只读剧本候选稿 |
| 质量审读 | 审读 | `script-review` | 与写作相同的格式技能 | 有证据锚点的审读报告 |

`CreativeProfile.script_format` 决定格式技能。中国格式与好莱坞格式互斥，不允许同时挂载。叙事结构只在项目明确选择后挂载，不提供默认模板替用户做决定。

## 3. 核心契约

### 3.1 创意开发

每个方向必须区别于其他方向的因果链，而不是换标题或换职业。至少提供：

- 主角可执行的行动；
- 可见的对抗系统；
- 可重复产生不同冲突的场景引擎；
- 关系与情感承诺；
- 升级机制、道德选择和结局代价；
- 能通过行为、空间、声音和物件表达的银幕身份；
- 制作影响及其取舍。

### 3.2 蓝图与 StoryMap

蓝图保存后续场景可引用的人物、关系、规则、压力线、事件与伏笔。StoryMap 的每个场景必须具有进入状态、即时目标、策略、对抗、转折、后果、知识变化、连续性变化和时长。

相邻场景应由“因此”或“但是”连接。只能用“然后”连接的场景必须合并、重构或说明其对照功能。

### 3.3 场景写作

主笔先完成戏剧设计，再做格式投影：

1. 角色用策略争取一个可执行目标；
2. 对抗力量主动抵抗；
3. 台词用于试探、隐瞒、招募、威胁、拖延、诱导或重构关系；
4. 内心通过行为、空间、节奏、声音、物件、沉默和选择外化；
5. 场景改变权力、知识、关系、风险或承诺；
6. 结尾交付后果，而不是总结。

删除一个场景若不影响因果、关系、知识边界或下一个决定，该场景必须重构或合并。

### 3.4 审读

审读顺序固定为事实与 StoryMap、因果、人物策略、连续性、节奏时长、可拍摄性与制作风险、交付格式。每条问题包含稳定锚点、证据、影响和最小修复方向。

严重度：

- `blocking`：破坏既定事实、因果理解或交付契约；
- `major`：明显削弱场景转折、人物能动性、连续性或集级兑现；
- `minor`：不阻断戏剧单元的局部清晰度、经济性、格式或制作观察。

## 4. 格式不是剧本思维

中国剧本格式与好莱坞格式只负责将同一个有效戏剧场景投影成不同交付规范：

- 中国格式：场景三要素、人物、画面、台词、OS、VO、成对闪回；
- 好莱坞格式：标准场景标题、动作、角色提示、对白、克制使用括注与转场。

运行时结构化输出仍由 Script 领域契约和 `format_profiles.py` 校验。技能不能掩盖结构化输出或 AgentScope block 解析错误。

## 5. 准入与变更规则

所有具有 `roles` 的剧本技能必须在 `skills/admission.json` 中登记：

- 状态必须为 `admitted` 才能自动或显式挂载；
- 每个技能必须具备正向、负向和回归三类用例；
- 未准入技能可保存在孵化目录，但运行时拒绝挂载；
- 技能内容和引用文件共同进入摘要指纹，修改后会改变 Agent 配置快照；
- 业务预算、篇幅、集数、场数、模型与产品策略必须来自项目设置或 Agent 交互，不得写入技能常量。

## 6. 下一轮评价基线

剧本技能质量不以“提示词更长”为目标，评价以下可观察指标：

1. 候选方向之间是否具有不同因果链和场景引擎；
2. StoryMap 中弱因果场景、重复功能场景和无兑现伏笔的比例；
3. 场景是否产生可观察状态变化；
4. 台词是否具有策略和潜台词，而非共享事实复述；
5. 审读发现是否有稳定锚点和可执行修复；
6. 中国/好莱坞格式是否只改变投影、不改变戏剧事实；
7. 人工修订后的最新确认版本是否进入后续场景上下文。

这些指标应在真实三集剧本验证中建立基线，再决定是否需要题材型、类型型或制作型扩展技能。禁止在没有对照样本时盲目增加技能数量。
