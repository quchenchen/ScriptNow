# 小说素材图谱分类规范

版本：v1.0  
状态：已批准实施  
适用范围：Novel 素材图谱。Script 领域必须另行定义，不得直接复用小说图谱契约。

## 1. 分类准入原则

一级类别必须同时通过以下判断：

1. **有利于 Agent 创作**：能直接支持检索、规划、续写、审读或一致性检查。
2. **必要且不可替代**：删除后会失去一种关键创作判断，不能由已有类别加属性表达。
3. **有利于作者和编辑理解**：无需了解图数据库或模型术语，也能判断该类别的意义。
4. **具备领域共识**：名称在叙事学、编辑实践或通用知识图谱中有稳定含义。

不能同时满足以上四项的概念不得新增一级类别，应放入 `attributes`、标签或关系描述。模型输出频率不是扩类依据。

## 2. 节点类型

持久化只保存稳定英文键；中文、英文名称属于界面翻译，不写入业务数据。

| 稳定键 | 中文显示 | 英文显示 | 对创作的核心作用 |
|---|---|---|---|
| `character` | 人物 | Character | 跟踪欲望、行动、弧线、知识与一致性 |
| `event` | 事件 | Event | 表达剧情发生了什么以及状态如何变化 |
| `organization` | 组织 / 群体 | Organization / group | 表达阵营、机构、家族及其集体利益 |
| `location` | 地点 | Location | 跟踪空间约束、场景复用与移动逻辑 |
| `object` | 关键物件 | Story object | 跟踪证物、道具、信物及其归属和作用 |
| `concept` | 观念 / 规则 | Concept / rule | 表达世界规则、主题观念和制度约束 |
| `relationship` | 关系 | Relationship | 把持续变化的关系本身作为可跟踪对象 |
| `story_thread` | 叙事线索 | Story thread | 跟踪伏笔、悬念、承诺、揭示与回收 |

章节是素材结构导航，不属于语义抽取类别；前端可使用只读的 `chapter` 展示类型。

## 3. 关系类型

| 稳定键 | 中文显示 | 英文显示 | 判断问题 |
|---|---|---|---|
| `causal` | 推进 / 因果 | Progression / cause | A 是否促成或改变 B |
| `emotional` | 人物 / 情感 | Character / emotion | A 与 B 的情感或信任如何变化 |
| `conflict` | 冲突 / 对抗 | Conflict / opposition | A 是否阻碍、威胁或伤害 B |
| `foreshadowing` | 伏笔 / 回响 | Setup / payoff | A 是否为 B 建立预期或完成回收 |
| `constraint` | 规则 / 约束 | Rule / constraint | A 是否限定 B 的可行选择 |
| `affiliation` | 归属 / 参与 | Affiliation / participation | A 是否属于、参与或位于 B |

`inference` 是证据状态，不是关系类型。推断关系必须在界面以不同线型展示，并保留置信度和来源。

## 4. 兼容收敛

旧值只在读取或写入边界归一化，不继续出现在界面与新数据中：

| 旧值 | 归一化为 |
|---|---|
| `faction`, `group` | `organization` |
| `world_rule`, `motif`, `theme` | `concept` |
| `foreshadow`, `setup`, `promise`, `mystery` | `story_thread` |

自由文本关系通过受控映射归入六类；无法确定时拒绝写入，不创建临时新类别。

## 5. 演进规则

- 模型必须按严格枚举输出，禁止自造类型。
- API 只返回规范键；前端通过统一字典显示本地化名称。
- 新增一级类别必须提交：不可替代性说明、至少两个 Agent 用例、编辑用户语言验证、迁移方案和契约测试。
- 分类体系变更必须升版本；不得以修复某一作品的抽取结果为由扩大全局枚举。
- 子类型、题材特有概念与作品专有概念优先放入属性和标签。

## 6. 展示投影

同一份图谱事实提供两种互补视图，不为展示目的新增节点类型：

- **关系图**：回答“谁与谁、什么与什么彼此牵动”，展示全部规范节点和关系。
- **故事时间线**：回答“故事如何依次发生”，按章节顺序投影 `event`、`relationship` 和
  `story_thread`。人物、地点、组织、物件与观念仍通过关系图和详情面板查阅。

时间线条目点击后必须复用同一节点详情，不复制或生成另一份创作事实。
