# 15 · 创作者中心产品纠偏

- **Status**: ready-for-agent
- **Type**: product / architecture / frontend / backend
- **Blocked by**: 01, 08, 09
- **Supersedes UI implementation**: 11～14 的右栏内容组织方式；保留永久约 1/3 右栏和后端领域能力
- **Est**: Epic，必须拆成 S/M slices
- **Source**: docs/product/V6-CREATOR-CENTERED-CORRECTION.md

## Problem

当前实现以系统机制组织界面，缺少目标规模、真实 Story Map、故事圣经和可解释的 Agent 创作任务链。创作者无法理解数据如何影响正文和后续章节。

## Required slices

1. Project Plan 与目标规模。
2. Volume/Chapter、Episode/Scene 真实 Story Map。
3. 故事圣经：概览、人物、组织关系、世界观、时间线、伏笔。
4. Chapter/Scene 创作意图与连续性快照。
5. 可解释 Agent Task、Delivery 与影响。
6. 审稿、Revision、Branch、Cascade 与交付闭环。

## Gate

真实创作者无需理解 Entity、Node、Context Pack 等内部术语，即可完成“规划作品 → 选择章/场 → 定义目标 → 写作/协作 → 审稿 → 采用变化 → 继续下一单元”的完整流程。
