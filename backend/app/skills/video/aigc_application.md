## §1 核心翻译表 · 理论 → 提示词

孙老师反复强调："AI 大模型其实学了很多摄影/电影作品，所以你跟它说焦段、光圈、景深、运镜、景别，它是能理解的。"

### 1.1 焦段 → 提示词

| 想要的情绪 | 提示词写法 |
|-----------|-----------|
| 临场感 / 大场景 | `广角镜头` / `14mm wide angle` / `wide shot` |
| 日常对话 | `35-50mm 标准镜头` / `standard lens` |
| 人像凝视 / 暧昧 | `85mm 镜头` / `85mm portrait` |
| 宿命 / 孤立 | `200mm 长焦` / `200mm telephoto` |
| 史诗结尾 / 命运 | `超长焦 400-800mm` |

### 1.2 光圈 / 景深 → 提示词

孙老师推荐三种写法（**都能识别**）：
- `光圈 F1.4`
- `光圈拍摄 F2.8`
- `景深 F1.6`

孙老师本人偏好：`光圈 F1.4`

| 想要的效果 | 提示词 |
|-----------|--------|
| 极浅景深（人物情绪特写） | `F1.4` 或 `F1.8` + 长焦 |
| 中景深（关系叙事） | `F4` |
| 深景深（史诗大场景全清晰） | `F8` 或 `F11` + 广角 |

## §2 孙老师的最高阶写法

> "**描述视觉感受，让模型自己去匹配**就好了。"

不要堆砌参数，而是写**视觉效果**：
- ❌ `85mm F1.4 浅景深 + 中景 + 平视 + 暖色调`
- ✅ `女孩独自坐着，远处的世界都模糊了，注意力只在她的眼神上`

孙老师课程里展示的两段对比：
1. 参数堆砌写法 → 中规中矩
2. 视觉感受写法 → 更有诗意，AI 反而更懂

**心法**：写"导演想让观众看到什么、感受到什么"，而不是写"摄影师按了什么按钮"。

## §3 AIGC 剪辑工作流（孙老师五步法）

### Step 1 · 分类素材
抽卡素材必须分三类：
- **好素材**：直接可用
- **废片**：局部 1-3 秒可用，需二创
- **神片段**：意外惊喜，必须保留并改剧情让路

判断关键句：
> "**先问有没有情绪，再问能不能用**。"

### Step 2 · 锁强画面
找到抽卡里**最强的那一帧或一秒**，作为整个剪辑的锚点。

### Step 3 · 反推结构
围绕强画面**反推前后**：
- 强画面放开头？→ 后面如何承接
- 强画面放高潮？→ 前面如何铺垫
- 强画面放结尾？→ 整段如何引导到这里

### Step 4 · 二创赋能
让"勉强"的素材成立的四大手法：
| 手法 | 说明 | 案例 |
|------|------|------|
| 慢放 | 提取局部 1-3 秒延长 | - |
| 倒放 | 改变运动方向 | - |
| 空进化 | 提取局部空镜头作为过渡 | 绝尘案例 |
| 声音重构 | 改音效让画面成立 | 浮光案例 |

### Step 5 · 顺应素材
> "传统剪辑控制素材，AIGC 剪辑顺应素材。"
不要硬把抽卡塞进既定剧本，而是让剧本为强画面让路。

## §4 AIGC 转场策略

### 4.1 AIGC 专属转场原则

> "AIGC 的核心原则只有一条——**用情绪连贯代替画面连贯**。画面可以不连续，但情绪必须流动。"

### 4.2 AIGC 转场万能兜底

| 场景 | 推荐 |
|------|------|
| 画面跳脱 | 硬切 + 空镜过渡 + 声音桥接 |
| 80% 普通场景 | 硬切 |
| 时间跳跃 | 叠化 |
| 情绪相似 | 匹配剪辑（颜色/动作/形状） |
| 情绪连续但场景跳 | J-Cut + L-Cut（声音桥接） |

## §5 声音设计 · AIGC 落地速查

### 5.1 三层必做清单

每条 AIGC 视频做完画面后，必须问自己：
- [ ] 第一层（叙述层）：人声 / 对白 / 旁白做了吗？
- [ ] 第二层（真实层）：环境音 + 动效有吗？（飞船配引擎、走路配脚步、风雨配音）
- [ ] 第三层（情绪层）：BGM 选得对吗？情绪密码匹配吗？
- [ ] 加分层：氛围铺底（1-3 层）有吗？

### 5.2 混音 dB 速查（剪映 / Pr 通用）

```
人声     ████████████████████ 0 dB    （永远最响）
BGM 默认 ████████████████ -6 dB       （正常时段）
BGM 闪逆 ████████ -12 dB              （人声出现时自动压低）
音效     ████ -20 dB                  （点缀）
氛围底床 ██ -25 dB                    （感觉到即可）
```

## §6 完整 AIGC 流程清单（孙老师两课综合）

任何 AI 视频项目按此清单走：

### A. 剧作设计（先于画面）
- [ ] 三幕式骨架：建立 / 对抗 / 解决
- [ ] 角色四阶段处境：渴望 → 障碍 → 顿悟 → 转变
- [ ] 情绪曲线：慢起 → 渐快 → 高潮 → 急停

### B. 镜头设计（写提示词前）
- [ ] 选景别（远 / 全 / 中 / 近 / 特 / 大特）
- [ ] 选焦段（广角 / 标准 / 中长焦 / 长焦）
- [ ] 选光圈（F1.4 / F4 / F8 → 浅 / 中 / 深景深）
- [ ] 选运镜（推 / 拉 / 摇 / 移 / 升 / 降 / 甩）
- [ ] 选节奏模型（聚焦 / 抽离 / 跟随 / 横扫 / 爆发 / 组合）

### C. 抽卡（生成素材）
- [ ] 多抽几张
- [ ] **不要删神片段**

### D. 剪辑（顺应素材）
- [ ] 分类：好 / 废 / 神
- [ ] 锁强画面
- [ ] 反推结构
- [ ] 二创赋能
- [ ] 选转场（80% 硬切 / 时间跳叠化 / 情绪相似匹配 / 情绪连续 J-L Cut）

### E. 声音设计（最后 30% 决定 95 分）
- [ ] 第一层：人声（对白 / 旁白）
- [ ] 第二层：真实层（动效 + 环境音）
- [ ] 第三层：情绪层（BGM）
- [ ] 加分层：氛围铺底 1-3 层
- [ ] EQ 与动态：扫音 / 留白 / 重音
- [ ] 混音三铁律：人声最响 / BGM 闪逆 -6 dB / 音效 -20 dB

### F. 风格统一（最后 10% 决定 95 vs 60）
- [ ] 画面色调 ↔ 音乐调性
- [ ] 剪辑节奏 ↔ BGM 节奏
- [ ] 字幕字体 ↔ 画面调性
- [ ] 段落过渡 ↔ 情绪 callback
