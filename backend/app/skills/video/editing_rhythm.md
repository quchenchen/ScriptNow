## §1 AIGC 剪辑 vs 传统剪辑

> "在 AIGC 的世界里，**会剪废片的人才是好剪辑师**。"

### 1.1 五大差异化对照表

| 维度 | 传统剪辑 | AIGC 剪辑 |
|------|---------|----------|
| **素材来源** | 按计划拍摄（2:3 / 3:1 / 5:1 比例） | 抽卡生成（不确定性） |
| **废片率** | 极低 | 极高 |
| **剧情关系** | 剧本决定画面 | 画面可以反过来改剧情 |
| **核心能力** | 标准的控制 | 转化随机 |
| **工作方式** | 控制素材 | 顺应素材 |

### 1.2 核心宣言

> "AIGC 剪辑不是整理素材，而是从随机里面重新发明新的故事。"

## §2 废片二创法 + 神片驱动法

### 2.1 废片二创的判断逻辑

抽卡素材到手后，**别问"能不能用"，先问"有没有情绪"**：

1. **局部研制法**：能不能在 15 秒里面截出 1 秒、3 秒、5 秒甚至 10 秒
2. **二创赋能**：通过慢放、倒放、空进化、声音重构，把废片赋予新生命

> "我有部作品叫**绝尘**，整部片子 50%-60% 以上都是废片，是一个废片组成的片子。"

### 2.2 绝尘案例 · 电吉他 solo 二创

孙老师的构思：
- 音乐是电吉他 solo
- 想用车流模拟手在琴弦上弹 solo 的状态
- 超过的车辆 + 遮挡物模拟琴弦
- **原始素材**：Seedance 2.0 之前的版本，前景护栏甚至没动，废片率极高
- **二创后**：完全成立，电吉他视觉化

### 2.3 神片驱动法

> "当 AI 给你一个意外的强画面的时候，**千万不要删掉**——虽然它和你剧本有出入。"

操作步骤：
1. 不要删
2. 让剧情为它让路
3. 先确定它放哪里：开头 / 中高潮 / 结尾
4. 再反推前后的结构

孙老师案例（剁铵台）：
- 原本提示词没让演员剁铵台
- AI 抽卡剁了一下，"翘皮"性格就出来了
- 决定保留这套素材，让配音演员专门写了"闭嘴！快跑！"的台词补上

### 2.4 AIGC 剪辑五步工作流

1. **判断素材**：好素材 / 废片 / 神片段（三者都不是 = 真垃圾）
2. **锁定抽卡最强画面**
3. **围绕强画面反推结构**
4. **用音乐节奏 + 音效让素材成立**（二创）
5. **顺应素材**：不是控制，是顺应

## §3 转场的本质

> "转场不是简单的叠加特效，它是**叙述的衔分**。"

### 3.1 高手 vs 新手

| 维度 | 新手 | 高手 |
|------|------|------|
| 思维 | 炫技型 | 虚视型 |
| 目的 | 展示转场效果 | 服务情绪衔接 |
| 观众感受 | 出戏 | 沉浸不跳戏 |
| 痕迹 | 故意暴露 | 藏起来 |

> "好的转场，观众是注意不到的。坏的转场，观众只会看到特效，缺忘的故事。"

### 3.2 警告

> "大量用黑屏、叠化做衔接，是你对画面**不够自信**的体现——因为你不知道如何衔接两个转场之间的关系，所以用了黑场。"

### 3.3 浮光案例 · 五种高级转场

孙老师在浮光中的转场设计：
1. **进房间转场**：用车盖颜色匹配 —— 摄像头放进车盖（黑色），打开车盖切到房间内（也是黑） = **颜色匹配转场**而非黑屏
2. **室内转室外**：精心设计的衔接
3. **比赛准备 → 比赛现场**：用漫画式分屏，三屏同时出现三辆车，三车同时停下 = 视觉构图转场
4. 留眼神接画面：用人物视线匹配下一画面
5. 整体策略：**不用单纯黑屏 / 叠化**，而是用更高级的衔接

## §4 五种基础转场（必须掌握）

### 4.1 硬切（Cut）
- **定义**：上一个画面的最后一帧 + 下一个画面的第一帧，无任何特效
- **使用率**：**80% 的场景用硬切就够**
- **原则**：要有自信，硬切是最强的

### 4.2 叠化（Dissolve）
- **定义**：两个画面叠加渐变
- **应用**：时间跳跃、回忆
- **变体**：可以选择不同的叠化方式（白叠、黑叠、闪叠等）

### 4.3 匹配剪辑（Match Cut）
- **三种类型**：
  - **颜色匹配**：黑→黑、红→红
  - **动作匹配**：上一个的动作接下一个的相似动作
  - **形状匹配**：圆→圆、线→线
- **效果**：高级、有隐喻、连贯性极强
- **示例**：浮光的车盖转场（黑转黑）

### 4.4 J-Cut（声先入画）
- **定义**：下一画面的**声音先进来**，画面后到
- **波形像 J 形**
- **效果**：勾住观众，让其想看看声音对应的画面

### 4.5 L-Cut（声后离场）
- **定义**：上一画面的**声音延续到下一画面**，但画面已切
- **波形像 L 形**
- **效果**：情绪还没结束，画面先到下一场景，情绪连贯

## §5 转场素材选择速查表

| 应用场景 | 推荐转场 |
|---------|---------|
| 快切 / MV / 动作片 | **硬切 + 甩镜** |
| 时间跳跃 / 回忆 | **叠化** |
| 两段情绪相似 | **匹配剪辑**（猫配猫、狗配狗、手举高配手） |
| 场景切换情绪连续 | **J-Cut + L-Cut** |
| AIGC 画面不连续 | **空镜过渡 + 声音桥接** |
| 万能兜底 | **硬切 + 空镜** |

> "传统剪辑的转场问题是怎么剪好看，AIGC 的核心原则只有一条——**用情绪连贯代替画面连贯**。画面可以不连续，但情绪必须流动、必须连贯。"

## §6 剪辑节奏铁律

### 6.1 不可信的衔接 → 用黑屏

孙老师在浮光案例中演示：
- 黑屏 = 给观众反映时间（"你怎么没说完？""怎么又跳场景了？"）
- 黑屏期间用 **J-Cut** 让下一段声音先入（如跑步机脚步声）

### 6.2 缓冲与释放

- 完全静音的留白 = 给观众**思考和吸收的时间**
- 关键剧情后必须留白
- 然后再 BGM 进入点 → 情绪重启

### 6.3 EQ 与音量动态（与剪辑节奏配合）

| 手法 | 用途 |
|------|------|
| 音量弦强（扫音） | 制造紧张感上升 |
| 音量弦弱（咒叫） | 制造下降、转折 |
| 完全静音 | 情绪放大、留白 |

子弹时间常用音量动态（扫音 + 静音 + 重音）。

### 6.4 风格统一 · 最后 10% 决定 95 分还是 60 分

剪辑完成后必问 4 个问题：
1. **画面色调和音乐调性是否同一语言**？冷蓝赛博画面 + 暖治愈钢琴 = 错配
2. **节奏是否同步**？快切画面 + 慢节奏 BGM = 错配
3. **细节是否统一**？字幕字体排版风格是否匹配画面（赛博风格用 QQ 糖糖字体 = 错配）
4. **段落过渡是否自然**？前后情绪 call back 是否一致（前段普通紧张 + 后段恐怖片紧张 = 不匹配）

> "风格统一不是好看的问题，是**可信的问题**。观众感受不到风格撕裂的具体原因，但能感受到这部作品不对劲。"

### 6.5 抄作业心法

> "找一部风格和你想做的最接近的作品，**逆向拆解它的色调、音乐、节奏、字体**，转化成自己的执行清单。**抄结构，不要抄内容**。抄作业是最快的成长路径——就像我们学唱歌，从模仿开始。模仿不丢人，连模仿都模仿不清楚才丢人。"
