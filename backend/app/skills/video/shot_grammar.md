## §1 焦段（人和镜头的距离）

> "镜头分为焦段，从 14mm 一直到 800mm，每一个焦段都有它相应的使用场景。"

### 1.1 通用焦段表

| 焦段 | 范围 | 典型用途 |
|------|------|---------|
| **广角** | 14-35mm | 狭窄空间 / 第一人称代入 / 史诗级大场景 / 低视角 |
| **标准** | 35-70mm | 双人对话、生活叙事、纪录片、家庭剧、文艺片 |
| **中长焦** | 70-135mm | 人像凝视、情感独白、暗恋戏、肖像广告、时尚 MV |
| **长焦** | 135-200mm | 情绪、宿命、孤立、愧世、史诗、不可抗拒 |
| **超长焦** | 200mm+ | 血缘、弧形、狙击视角、追逐细分、史诗结尾、命运感 |

### 1.2 800mm 长焦应用
拍赛事、拍狮子老虎、拍飞机，甚至拍月球。

### 1.3 关键铁律

> **"恐怖场景如果用 800mm 或 200mm 长焦去拍，是非常奇怪的——焦段不能乱用。"**

## §2 镜头类型 · 十大情绪密码

> "镜头是有情绪密码的——什么样的场景，只能用什么样的镜头。"

### 2.1 鱼眼镜头
- **情绪**：迷幻、超现实
- **场景**：滑板、药物体验、梦境、嘻哈 MV、儿童视角

### 2.2 微距镜头
- **情绪**：精致、私密、被忽视的世界
- **场景**：化妆品广告、美式广告、自然纪录片

### 2.3 移轴镜头（孙老师特别喜欢用）
- **情绪**：玩具感、上帝视角、抽离、童趣、模型化的现实
- **场景**：节日、品牌创意广告
- **AIGC 写法**：把"移轴镜头"四个字当 prompt 直接给 AI

### 2.4 俯拍镜头
- **情绪**：渺小、无助、被审视、上帝视角、宿命感
- **场景**：人物巨大空间里的孤独感、场景俯瞰、悬疑片、品牌宏观趋势
- **铁律**：想拍渺小感**只能用俯拍 + 广角**，中长焦从上往下拍也出不来渺小感

### 2.5 仰拍镜头
- **情绪**：强大、威严、压迫感、敬畏感
- **场景**：英雄登场、反派威胁、老板出场

### 2.6 荷兰角（蔡导和孙老师都特别爱用）
- **情绪**：失衡、错乱、精神崩溃、危机、降临、情绪不安
- **场景**：恐怖片心理崩溃、动作片打斗眩晕、悬疑片真相揭露、超现实反派登场
- **加分**：手持荷兰角质感更强

### 2.7 平视镜头
- **情绪**：日常、平视、克制、真实
- **焦段**：50-70mm
- **场景**：新闻联播、访谈对话、纪录片人物介绍、真诚相的品牌片
- **警告**：**蔡导特别不喜欢这个镜头**，太新闻联播。除非特殊强调，不要乱用——会让片子平平无奇

### 2.8 过肩镜头
- **情绪**：对峙、视角带入、关系张力
- **场景**：好莱坞大片对话、双人对话戏、谈判、对峙、采访、约会场景
- **使用频率**：好莱坞大片用得极多

### 2.9 主观视角（第一人称）
- **情绪**：带入感、临场、紧迫、私密
- **场景**：Vlog、第一人称体验
- **AIGC 常见错误**：想表达"带入紧迫私密"却用了普通镜头，结果完全没有带入感、平平无奇

### 2.10 跟拍镜头
- **情绪**：沉浸、节奏跟随、连续性、流动感
- **场景**：长镜头叙事（角色从左走到右）、人物行走、动作追逐、纪录片跟随、MV 节奏段落

## §3 运镜 · 七大情绪密码

> "运镜也不能随便乱运、乱应用。"

### 3.1 推镜头
- **情绪**：揭示、聚焦某事件、心理深入、悬念递进、情绪逼近
- **导演潜台词**："注意了，重点要来了，看清楚这个人/细节"
- **效果原理**：主体逼近过程中，观众注意力被强制收窄，从画面信息很多到只能看到 80% 占据的脸

### 3.2 拉镜头
- **情绪**：抽离、揭示环境、孤立感、收尾感、命运全景
- **导演潜台词**："等等，你以为你看到的就是全部吗？我让你看更多真相"
- **效果原理**：主体远离，画面信息从局部拓展到整体

### 3.3 摇镜头
- **情绪**：环境展示、引导、扫视、连接、信息拓展
- **导演潜台词**："别急，我带你看看这边发生了什么"
- **运动方式**：机位不动，镜头水平左右转动（**模拟人转头**）

### 3.4 移镜头（"移开了座位"）
- **情绪**：沉浸、跟随、流动、节奏并行陪伴
- **导演潜台词**："我和你一起走，你看到的世界就是我看到的世界"
- **运动方式**：机位横向移动（**离开座位的横向**），常用伴随横移

### 3.5 升镜头
- **情绪**：释放、超越、营造希望、宏大场景、上帝视角浮现
- **导演潜台词**："故事到这里要变大了，我们要看到更多的维度了"
- **铁律**：**首帧和尾帧画面**——尾帧必须信息量盖过首帧，否则升镜头是失败的

### 3.6 降镜头
- **情绪**：坠落、压迫、聚焦、命运零镜、揭晓局部
- **导演潜台词**："我先让你看到全貌，然后把视野锁到某一个点"
- **铁律**：不一定大变小，也可以聚焦/揭示

### 3.7 甩镜头
- **情绪**：冲击、转场、混乱、节奏爆发、信息断裂
- **导演潜台词**："不要思考了，我现在就要换场景换情绪，我打断你"
- **可组合**：与推/拉组合形成"刷甩"

## §4 镜头组合的本质

> "刚才上面所说的镜头都是基础理论知识，它们就像 Do Re Mi Fa Sol La Si 七个音符，可以自由组合搭配，来表现你当下想表达的情绪。"

孙老师的月云案例镜头序列示范：
- 推 → 固定镜头甩 → 前推 → 前推下下移 → 再前推 → 上抬 → 斯坦尼康环绕 → 升格

**反思问题**：
- 不知道推镜头是递进 → 写不出递进感的提示词
- 不知道拉镜头是揭晓 → 写不出揭晓感的提示词
- 不知道横移是扫场景 / 是引导 → 写不出引导感
- 不知道横移是交代跟随 → 写不出跟随感

**结论**：不了解每个镜头的基础情绪密码，组合镜头无从谈起。

## §5 AIGC 提示词中的焦段/光圈写法

孙老师的写法示例：
- `光圈 F1.4` 或 `光圈拍摄 F2.8` 或 `景深 F1.6`（三种写法都能识别）
- 推荐用 `光圈 F1.4` 来凸显景深
- 焦段示例：`使用 85mm 镜头 + F1.4 光圈 + 景深` + 正常描述

最高阶写法：**"描述视觉感受，让模型自己去匹配"** —— 不指定具体参数，只描述要的视觉效果。
