# 男频爽文短剧 · 创作知识包

## 简介

本知识包为**男频爽文短剧**类型提供完整的叙事手法参考。适用于都市战神、龙王归来、赘婿逆袭、狂婿归来、兵王重生等子类型。

## 核心理念

- **反差 = 一切** — 主角"看似普通/落魄，实则大佬"的落差越大，爽感越强。开局越低越好，揭穿越晚越爽
- **憋屈到爆发的比例** — 前半段憋屈铺垫（3-5集），后半段渐进揭穿（每集揭一层），最后一击必杀
- **身份揭穿是节奏引擎** — 一次揭穿一层身份，敌方阵营 KO 一批人。全剧至少 3 次大揭穿
- **单线制敌** — 一集一个主要敌人打完，不要多线并行
- **不要主角说自己牛** — 让配角/敌人震惊、跪求、当众打脸 —— 越是主角淡定越有味

## 爽点选型（选主爽点 1 种 + 副爽点 1 种）

| 爽点 | 心理机制 | 典型场景 |
|------|----------|----------|
| **优势/金手指** | 独有能力，观众代入优越感 | 战神/龙王身份、绝世医术、上古传承 |
| **归属** | 团结/家国/门派 | 兄弟归来、宗门认主、家国大义 |
| **秩序** | 逻辑还原真相 | 复仇/查案/身世揭穿 |
| **打脸** | 前期被小看，后期反杀 | 岳父/表哥/前女友道歉、跪求 |

**慎用**：性/暴力等生理级爽点（易踩审核线）

## 集数-爽点节奏推荐

| 集数区间 | 建议节奏 |
|----------|----------|
| 1-3 集 | 建立憋屈开局 + 埋身份线索（不揭穿） |
| 4-6 集 | 第一次小爆发（局部反击） |
| 7-15 集 | 中期揭穿一层身份 + 打倒中层反派 |
| 16-25 集 | 第二次揭穿 + 遇更强反派 |
| 26+ 集 | 终局揭穿 + 最终对决 |

## 关键约束

- **主角人设一致性**：核心性格（如"冷淡话少的深藏不露"）不允许中途大改
- **身份揭穿只往上不往下**：不允许"被误会成大佬 → 其实是普通人"这种反爽转折
- **反派要够狠够蠢**：狠 = 铺主角憋屈，蠢 = 让反杀合理
- **每集必打脸**：从第 4 集开始每集必须有至少一个"局部打脸"瞬间
