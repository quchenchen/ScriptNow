# 悬疑推理短剧 · 创作知识包

## 简介

本知识包为**悬疑推理短剧**类型提供完整的叙事手法参考。适用于连环案/密室/心理惊悚/身世谜团/复仇追凶等子类型。

## 核心理念

- **谜面越具体越诱人** — "谁是凶手"不如"死者手里为什么攥着 X"具体
- **线索必须公平** — 所有真相要用的线索必须在揭穿前给到观众（fair play），不能凭空冒出来
- **红鲱鱼要多而巧** — 每集埋 1-2 条假线索，误导观众和主角
- **反转不靠信息藏，靠角度换** — 同一个事实，换个角度就变成另一个真相
- **单线追凶 + 支线人性** — 主线破案，副线揭露每个角色不为人知的一面

## 谜面类型（选主谜 1 种 + 副谜 1-2 种）

| 谜面 | 张力来源 | 典型场景 |
|------|----------|----------|
| **凶手是谁** | 熟悉的人可能有嫌疑 | 每集怀疑一个角色，逐个洗脱嫌疑 |
| **动机是什么** | 已知凶手，但为什么杀 | 主角调查动机，动机比凶手更震撼 |
| **手法是什么** | 密室/不可能犯罪 | 每集给一个可能的手法，逐个否定 |
| **受害者是谁** | 死者身份不明 | 一步步还原死者的秘密身份 |
| **主角是谁** | 主角自己身世成谜 | 主角查案查到自己 |

## 集数-线索节奏推荐

| 集数区间 | 建议节奏 |
|----------|----------|
| 1-2 集 | 案件发生 + 主角介入 + 立第一个疑犯 |
| 3-8 集 | 每集查一个角色，每集揭一层秘密（不指向真凶） |
| 9-15 集 | 中期反转：第一波认为的真相被推翻 |
| 16-22 集 | 真凶浮现但主角还差最后一环 |
| 23+ 集 | 最终对决：智力对抗或情感对抗 |

## 关键约束

- **fair play 原则** — 所有揭穿真相用的线索必须在此前 3 集内出现过
- **每集必解一个小谜** — 观众离开时必须有"哦原来是这样"的满足感
- **真凶不能是最先怀疑的那个** — 至少要有 2 次错认
- **动机必须合乎人性** — 不能是"为了钱"这种俗套，要能让观众理解甚至同情
- **主角必须有代价** — 破案过程中失去点什么（朋友/信念/自己的过去）
