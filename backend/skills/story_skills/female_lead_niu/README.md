# 女频虐恋短剧 · 创作知识包

## 简介

本知识包为**女频虐恋短剧**类型提供完整的叙事手法参考。适用于都市虐恋、豪门恩怨、替嫁替身、闪婚闪离、破镜重圆等子类型。

## 核心理念

- **虐点密度决定留人** — 单位时长内的情感冲击（误会/隐忍/牺牲）频次
- **误会驱动 vs 阴谋驱动** — 短剧偏爱阴谋驱动（第三方作梗），因为反转来得更快
- **甜虐平衡** — 3 虐 1 甜的节奏最抓人 —— 全虐则劝退，全甜则乏味
- **女主要有骨气** — 隐忍不是软弱，是**主动选择不解释** —— 观众替她憋屈才代入
- **男主必须补偿** — 后期跪、后期追、后期悔 —— 越极端越爽

## 虐点选型（选主虐点 1 种 + 副虐点 1 种）

| 虐点 | 情感机制 | 典型场景 |
|------|----------|----------|
| **误会隐忍** | 女主背锅，观众心疼 | 被诬陷偷东西 / 被扣屎盆子 |
| **身份错位** | 替身/替嫁/失忆 | 男主爱着"另一个她"或"记忆里的她" |
| **家人筹码** | 女主为家人牺牲爱情 | 弟弟手术费/母亲欠债 |
| **孩子筹码** | 隐孕/夺子 | 女主怀孕独自离开 / 多年后带娃归 |
| **绝症/时限** | 生命倒计时 | 女主查出绝症选择推开男主 |

**慎用**：车祸失忆、堕胎、原生家庭老套梗 —— 观众看腻

## 集数-虐恋节奏推荐

| 集数区间 | 建议节奏 |
|----------|----------|
| 1-3 集 | 建立矛盾（隐孕/替嫁/误会） + 撂狠话离开 |
| 4-8 集 | 女主独立崛起（副线立起来） + 男主开始怀疑真相 |
| 9-18 集 | 真相碎片式揭露 + 男主追妻火葬场开始 |
| 19-25 集 | 大真相揭穿 + 男主大跪 + 女主犹豫 |
| 26+ 集 | 破镜重圆 or 决绝分开（BE/HE 二选一，短剧多 HE） |

## 关键约束

- **女主人设一致性**：核心气质（清冷 / 温柔 / 骄傲）贯穿始终，不允许中途大改
- **男主的道歉必须迟到 + 昂贵** —— 早道歉没爽感，便宜道歉观众不买账
- **真相碎片要错开揭穿** —— 一集揭一片，逼男主追、逼观众看
- **副 CP 要立起来** —— 女主的女闺蜜 / 男二 —— 不能只有男女主两个人的世界
- **反派女配要有分量** —— 越坏越好、越蠢越好，最后 KO 越惨越爽
