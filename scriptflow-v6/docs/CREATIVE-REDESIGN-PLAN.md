# ScriptFlow 创作者视角产品重构方案

> 调研方法：以编剧身份完成「黑冰·双强博弈」80集竖屏剧全流程操作，记录每个创意断裂点。
> 参考系统：StoryPlay(Story-MCP)·Toonflow·MuMuAINovel·ViMax

---

## 一、创意断裂点全记录

### 断裂1：进入项目后 —— "我现在该干什么？"

**现状**：创建项目 → 直接进入空白工作台。StoryMap 显示 240 个「待规划」单元，三模式切换不知所指。

**编剧心理**：我刚输入了创意种子，现在最想知道的是 Agent 理解了我的意图没有。不希望看到 240 个空壳，希望看到 3-5 个"这个方向怎么样"的具体提案。

**参考 StoryPlay**：入口按创作任务组织，用户一眼知道能做什么。

---

### 断裂2：StoryCore 评审 —— "这不是我想要的，但我没法表达"

**现状**：Agent 生成 3 个 StoryCore 候选，我必须"采用/拒绝"二选一。拒绝后没有对话、没有修正、没有"第三个方向好但主角不对"的反馈路径。

**编剧心理**：创作是迭代的。我需要能说"第二个方向不错，但主角应该从刑警换成卧底记者"，然后 Agent 基于我的反馈重新发散。当前系统不允许这种对话。

**创意断裂**：Candidate/Adopt 模式在"最终交付物"层面是正确的，但在"创意探索"阶段过于刚性。创作者需要的是**生长**，不是**投票**。

---

### 断裂3：StoryMap 240 单元 —— "我看到一座无法逾越的山"

**现状**：80集×3场 = 240 个「待规划」单元在左侧目录展开。编剧本能反应是窒息。

**编剧心理**：专业编剧不会一次性规划 240 个单元。他们会先写"一句话梗概 → 三幕结构 → 10集大纲 → 第1集剧本"。系统应该渐进式展开，而不是一次性摊开全貌。

**参考 MuMuAINovel**：灵感→大纲→角色→逐章撰写，分阶段递进。

---

### 断裂4：生成第一场 —— "机器在写，不是我"

**现状**：点击「生成下一场」→ 等待 30 秒 → 得到 800 字正文。内容有具体时间地点人物，但缺乏"我"的风格印记。角色对话像法律文书，缺少人味。

**编剧心理**：我希望 Agent 做的是**放大我的创意**，不是**替代我的写作**。我应该能：
- 在生成前写 50 字"这场戏的氛围和关键对话方向"
- 在生成后标注"这句对白太冷，帮我改得更像男女之间试探性的对话"
- 看到 Agent 为什么这么写——它引用了哪个角色设定、哪个伏笔、哪条创作指令

**创意断裂**：当前 Agent 的"黑箱感"太强。输出质量不差，但创作者不知道它为什么这么写，也无法精细调控。

---

### 断裂5：AI 编辑 —— "我说'润色'，它只改了标点"

**现状**：Mock 运行时 AI 编辑只做标点替换（`, → ，`）。真实 AgentScope 的编辑质量未知，但交互模式单一——只有 6 个预设模式（缩写/扩写/润色/对白/节奏/自定义）。

**编剧心理**：真正的剧本修改不是"把这 200 字缩写到 120 字"。是"这段对话太直白了，要更有潜台词"，是"这个场景的情绪转折太突兀，加 3 句内心独白"。AI 需要的不是模式按钮，是理解**修改意图**。

**参考 ViMax**：context_pack 携带完整上下文，Agent 基于场景理解做出精准修改。

---

### 断裂6：连续性 —— "系统告诉我有1个角色2条伏笔，然后呢？"

**现状**：连续性面板显示"实体 2 · 伏笔 0 · 风险 0"，但没有任何创作建议。编剧看到这些数字，不知道对自己写下一场戏有什么帮助。

**编剧心理**：连续性系统应该**主动提醒**我：
- "汪静飞在上一场结尾处于戒备状态，这一场的开场对白应该从戒备开始，而不是从平静开始"
- "郭小鹏还没有出场，按照你的创作指令（每集一场直接交锋），这一场应该安排他的戏份"
- "你设定的伏笔'签字日期之谜'应该在场景5-8之间被提及，现在进度4/80"

**创意断裂**：连续性系统是**被动诊断**，不是**主动导航**。它应该像副驾驶，而不是仪表盘。

---

### 断裂7：角色管理 —— "我加了郭小鹏，但 Agent 不知道他是什么样的人"

**现状**：通过 Story Bible 添加了郭小鹏（身份/功能/声音描述），但生成的剧本中郭小鹏的对白仍然是功能性的，没有体现"说话慢条斯理，每句话都像在下棋"的声音设定。

**编剧心理**：我花了时间填写角色声音，但这个信息没有被 Agent 有效吸收。系统缺少一种机制让我验证"Agent 是否正确理解了我的角色设定"。

---

### 断裂8：创作指令 —— "我写了规则，但不知道生效了没有"

**现状**：添加了"每集必须有汪静飞与郭小鹏的直接对话"的创作指令。但下一场生成时，没有任何证据表明 Agent 读取或遵循了这条指令。

**编剧心理**：我需要透明的"指令执行报告"：Agent 在生成时读取了哪些指令？哪些被遵循了？哪些被省略了（以及为什么）？

## 三、Agent 精密发散架构设计

### 核心理念

**Agent 不是替代创作者，而是放大创作者意图的"创意棱镜"。** 

把一束白光（创作者的模糊想法）折射成光谱（多个具体方向），让创作者选择最接近内心的那个频率，然后继续折射。

### 三层发散模型

```
种子层 (Creator)
  └─ "我想把黑冰改成80集竖屏短剧，双主角高智商博弈+情感拉扯"
     │
发散层 (Agent Prism) ── 不要"写一个方案"，要"从5个角度折射我的意图"
  ├─ 角度1: 如果以'程序正义 vs 个人复仇'为核心冲突？
  ├─ 角度2: 如果汪静飞不是刑警，而是被郭小鹏害死的线人的妹妹？
  ├─ 角度3: 如果时间线倒叙——从审判日开始，每集回溯一个关键证据？
  ├─ 角度4: 如果第一场戏就是两人的第一次审讯，全程只在一个房间？
  └─ 角度5: 如果加入第三人称叙述者（黑冰原著旁白风格）作为结构？
     │
选择层 (Creator) ── 我选角度4，但把主角改回刑警
     │
深化层 (Agent Prism) ── 基于角度4+修正，进一步折射
  ├─ 开场对白可以有几种风格：冷峻法律体/试探性暧昧/赤裸威胁
  ├─ 结局可以有几个方向：审判定罪/证据不足释放/汪静飞主动销毁证据
  └─ 第1集的3个场景可以如何分配时间？
```

### 每个对话回合的 Agent 行为准则

1. **不只给答案，给选择**：每次输出提供 2-4 个差异化选项，而不是一个"最佳方案"
2. **解释为什么**：每个选项附带"基于你的XX设定，我提出这个方向，因为……"
3. **记住偏好，主动应用**：一旦创作者选择了某类风格/节奏/人物关系，后续自动沿袭
4. **暴露矛盾，而非掩盖**：如果创作者的新要求与之前设定冲突，主动指出来并给出调和方案
5. **渐进式细化，拒绝一次性摊牌**：先给结构，确认后再给场景；先给场景骨架，确认后再写对白

### 创作者交互界面

不是"聊天窗口"，而是**创作画布+智能探针**：

```
┌──────────────────────────────────────────────────────┐
│ 作品空间                     [大纲模式] [场景模式]     │
│                                                      │
│  ┌─────────────┐  ┌──────────────────────────────┐   │
│  │ 故事结构     │  │ 当前场景：EP01·SC01           │   │
│  │             │  │                              │   │
│  │ EP01 ▸      │  │ 【场景】舰桥半岛·杨秋别墅·夜  │   │
│  │  SC01 ✓     │  │                              │   │
│  │  SC02 …     │  │ △刘眉站在门外。她的手指在     │   │
│  │  SC03       │  │ 发抖，但眼神很平静。          │   │
│  │ EP02        │  │                              │   │
│  │ EP03        │  │ AI 探针 ▸                    │   │
│  │ …           │  │  "这段开头节奏偏慢，如果从    │   │
│  │             │  │  门铃声响起的瞬间切入？"      │   │
│  └─────────────┘  └──────────────────────────────┘   │
│                                                      │
│  创作指令 ▸ "每集必须有双人交锋" · 已遵循 (5/5)      │
```

## 四、分阶段执行计划

### Phase 1: 创意起点重构（不是"修复Bug"，是"重新定义创作入口"）

| # | 任务 | 为什么从创作者视角重要 |
|---|------|----------------------|
| D1 | **发散式 StoryCore 生成**：Agent 不只给 3 个方案，而是从 5 个角度折射意图，每个角度附"为什么这么想" | 创作者需要看到自己意图的多种可能性，而不是 AI 的三个猜测 |
| D2 | **选择→对话→深化循环**：采用一个方向后，Agent 基于"你选择了XX，更贴合的3个细化方向是……"继续发散 | 创作是逐层收敛的，不是一次性投票 |
| D3 | **偏好学习**：每次选择后记录风格/节奏/人物关系偏好，自动应用到后续生成 | 创作者不应该重复说"我喜欢冷峻风格" |
| D4 | **创作画布替代 StoryMap 展开**：只展示下一层结构（3集大纲），点击展开才看到细节 | 240单元一次性摊开是窒息，渐进展开是探索 |

### Phase 2: 生成过程透明化

| # | 任务 |
|---|------|
| D5 | **生成前预览**：显示 Agent 将要使用的角色设定、创作指令、上下文——创作者可以在此修改 |
| D6 | **生成后溯源**：标注每一段对白/动作引用了哪个角色设定、哪条指令 |
| D7 | **指令遵循报告**：生成完成后，明确列出"已遵循/部分遵循/未遵循"的指令及原因 |

### Phase 3: 智能副驾而非仪表盘

| # | 任务 |
|---|------|
| D8 | **连续性主动建议**：不是显示"1个角色2条伏笔"，而是"下一场戏应该让郭小鹏出场，因为已过2集未出现，且你设置了每集交锋规则" |
| D9 | **伏笔进度导航**：显示每条伏笔的"埋设→强化→回收"时间线，提前提醒即将超期的伏笔 |
| D10 | **角色一致性检查**：如果Agent生成的郭小鹏对白不符合已设定的"慢条斯理"声音，主动标记并建议修改 |

### Phase 4: AI 编辑的创意维度

| # | 任务 |
|---|------|
| D11 | **意图式编辑**：不是"缩写/扩写/润色"，是"让这段对话更有潜台词""让这个转折更突兀""让这个角色更脆弱" |
| D12 | **对比式采纳**：采用 AI 修改时，并排显示原文与修改，标注变化点，创作者可以部分采用 |
