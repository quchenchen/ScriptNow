## 二、Bug 清单

### 🔴 P0 — 阻塞级 (用户无法完成核心流程)

| # | Bug | 根因 | 影响 |
|---|-----|------|------|
| B1 | **StoryMap 不联动** | `draft_opening` 未传 `story_map_unit_id` 时不设置 `manuscript_unit_id`；`adopt_manuscript` 查不到关联的 StoryMapUnit | 生成再多场景，StoryMap始终显示0/240 |
| B2 | **文档内容为空** | `save_document` 创建空 ManuscriptDocumentVersion 不复制 adopted_content | 前端无法显示已采用正文 |
| B3 | **AI 编辑不生成候选** | P14正文为空→P15调用无内容可编辑 | 依赖B2修复 |

### 🟡 P1 — 体验级

| # | 问题 | 影响 |
|---|------|------|
| B4 | 角色名仅自动提取1个(汪静飞)，需手动添加郭小鹏 | 连续性不完整 |
| B5 | `runtime/status` mode 不跟随 LLM 配置 | 显示"demo"实际"agentscope" |
| B6 | 草稿生成不创建 Scene 对应关系 | scenes 表与 manuscript_units 关联弱 |
| B7 | 前端项目卡片点击偶发不导航 | 需双击/Vue事件冒泡 |

### 🟢 P2 — 优化级

| # | 建议 |
|---|------|
| O1 | 自动从已采用正文提取角色(郭小鹏)并加入 story bible |
| O2 | 生成草稿时自动匹配 StoryMap 首个"待规划"单元 |
| O3 | 前端支持直接在目录上点击"生成此单元" |
| O4 | 角色面板支持从已有实体中选择(relationTo/From) |
| O5 | 故事资料增加已采用正文的角色状态摘要 |
