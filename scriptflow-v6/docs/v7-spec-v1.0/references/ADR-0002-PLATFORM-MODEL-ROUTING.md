# ADR-0002：模型由平台路由，用户购买创作能力而非自行配置 LLM

## 决策

ScriptFlow 的普通用户不能查看、选择或配置具体模型、Provider、API 地址和密钥。模型属于平台基础设施，由平台根据创作任务、质量门槛、上下文规模、响应时延、成本预算和商业套餐进行路由。

用户可理解和选择的是：

- 创作能力等级与适用场景。
- 本次任务预计消耗的额度。
- 是否使用高质量重写、深度审阅或长上下文分析。
- 任务状态、交付依据和质量检查结果。

用户不可见的是：

- Provider 与具体模型名称。
- API Key、Base URL 和模型参数。
- 模型降级、重试和供应商切换细节。

## 路由输入

```text
Task Type + Context Size + Quality Gate + Subscription Plan
+ Budget Ceiling + Latency Target + Provider Health
→ Model Route
```

项目可以锁定“能力策略版本”，但不锁定供应商名称。平台在满足同一质量契约的前提下可以更换底层模型；若模型变化可能改变作品风格或质量，则必须创建新的能力策略版本并通过 Golden Project 回归。

## 安全边界

- Provider Credential 只能通过服务端环境或未来的密钥管理系统注入。
- 普通用户 API 不提供模型配置写入口。
- 前端只展示能力等级、额度和任务状态。
- 运营管理端与普通创作端分离，管理端后续单独授权。

## 商业含义

不同 LLM 的成本差异转换为平台套餐、任务额度与增值能力，而不是让用户自行承担模型配置复杂度。一次创作任务可由多个模型协作，但对用户表现为一个可解释的 Agent Team 交付。
