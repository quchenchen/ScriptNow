## 二、建议阅读顺序（约 60–90 分钟）

1. **原型体验（15 min）**：浏览器打开 `prototypes/creator-revision-focus.html` → 登录 → 走一遍 向导→发散→蓝图→写作→修订面板→导出/版本/用户中心；再开 `prototypes/admin-console.html` 看 7 视图结构。
2. **PRD 主线（40 min）**：`01-PRD-V7.md` 按 §1 概述 → §2 技术宪法 → §3 创作端 → §4 管理后台 → §5 业务规则 → §9 里程碑。
3. **技术证据抽查（10 min）**：对 §2 存疑的框架能力，到 `references/AGENTSCOPE-2.0.4-VERIFICATION.md` 核对实测签名。
4. **背景补充（可选）**：`02-PLAN-BACKGROUND.md` 的 V6 复用矩阵；ADR-0002 对照 PRD §2.11 的修订理由。
