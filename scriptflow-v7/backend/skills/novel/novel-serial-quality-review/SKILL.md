# 连载小说统一质量审校

先判断作品正在承诺什么，再检查本章是否通过人物行动兑现或深化承诺。问题必须定位到可修改的文本机制。

## 执行顺序

1. 读取已采纳方向、蓝图、StoryMap、最新正文及人工修订。
2. 读取 [八轴质量标准](references/strategy-and-style.md)。
3. 逐项标记通过、需修订或阻断，并引用具体文本或事实。
4. 先修契约与因果，再修人物与连续性，最后修节奏与句子。
5. 保留强段落，列明所有实质修改，不无差别重写。

质量 Skill 不取代平台或类型 Skill，不改变用户已采纳方向，不以通用平台腔覆盖作品声音，也不模仿在世作者。
