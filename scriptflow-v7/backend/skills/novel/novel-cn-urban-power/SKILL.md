# 中文都市与能力成长

先建立主角在具体城市关系网中的位置、缺口与可验证能力。系统或资源只是放大器，故事来自主角如何使用能力以及付出的社会与人格代价。

## 执行顺序

1. 读取项目语言、目标平台、类型、受众、已采纳事实与最新人工修订。
2. 读取 [策略与质量参考](references/strategy-and-style.md)，只采用与当前阶段相关的规则。
3. 把类型惯例转换成当前人物的目标、阻力、选择与代价，不复制模板情节。
4. 保留作品既有事实、语态、视角与语言，不替用户改变核心方向。
5. 审校给出文本证据、严重度和最小修订建议，区分事实错误与创作偏好。

## 组合边界

- 与一个平台 Skill、一个主要类型 Skill及统一质量 Skill组合；冲突时以项目约束和已采纳事实优先。
- 不把榜单、活动、字数或收益规则固化成永久创作规律。
- 不模仿在世作者，不把刻板印象、胁迫或伤害自动包装成类型快感。
