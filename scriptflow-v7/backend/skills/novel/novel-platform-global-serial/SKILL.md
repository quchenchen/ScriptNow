# 海外英文连载策略

Write for phone reading without flattening the prose. Establish the protagonist’s want, pressure, genre promise, and relational stakes early. Make every installment produce a meaningful state change and end on a live dramatic question rather than a manufactured interruption.

## 执行顺序

1. 读取项目语言、目标平台、类型、受众、已采纳事实与最新人工修订。
2. 读取 [策略与质量参考](references/strategy-and-style.md)，只采用与当前阶段相关的规则。
3. 把类型惯例转换成当前人物的目标、阻力、选择与代价；不要复制模板情节。
4. 产出时保留作品既有事实、语态、视角与语言，不替用户改变核心方向。
5. 审校时给出文本证据、严重度和最小修订建议，并区分事实错误与创作偏好。

## 组合边界

- 本 Skill 与一个平台 Skill、一个主要类型 Skill及统一质量 Skill组合；冲突时以项目明确约束和已采纳事实优先。
- 不把平台榜单、活动规则、更新字数或收益政策固化为永久创作规律；发布前另行核验。
- 不模仿在世作者，不把刻板印象、胁迫或伤害自动包装成类型快感。
