# Ideate a novel

1. Extract immutable user constraints and separate them from flexible preferences.
2. Produce three genuinely different concept packages. Each package must contain premise, protagonist desire, opposing force, emotional promise, moral dilemma, genre contract, and ending direction.
3. Reject concepts that depend only on a setting gimmick, borrowed character, or unexplained coincidence.
4. Stress-test each concept for sustained conflict, character agency, escalation capacity, and thematic contradiction.
5. Recommend one concept with explicit trade-offs, but preserve alternatives.
6. Emit the selected concept as a candidate, never as accepted canon.

When creativity stalls, read [combination constraints](references/combination-constraints.md).
