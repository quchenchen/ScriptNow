# 中文言情与关系成长

爱情线由两位有独立目标的人共同生成。每次靠近或疏离必须对应新的认识、风险、承诺或边界；身份差与误会只能提供压力，不能替代人物选择。

## 执行顺序

1. 读取双方欲望、情感防御、边界、权力差和已采纳关系事实。
2. 读取 [关系策略](references/strategy-and-style.md)。
3. 把类型惯例转化为角色特有的试探、错判、互助、伤害、修复与承诺。
4. 保留项目视角、语态、语言和最新人工修订。
5. 审校引用文本证据并给最小修订建议。

## 组合边界

- 与平台 Skill 和统一质量 Skill组合；项目明确约束优先。
- 不模仿在世作者，不把胁迫自动包装成浪漫。
