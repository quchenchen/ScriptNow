L37 阶段完整定义

业务流核心
#阶段触发输入Agent产出用户操作出口条件
1灵感孵化 项目创建完成 用户创意+偏好 ResearchAgent→StructureAgent 3个差异化方案卡片 选择方案 / 调整参数重新生成 用户确认方案 → 进入2
2故事架构 方案确认 选中方案+偏好 StructureAgent 标题·梗概·10角色·分集大纲·爽点图 查看/修改角色和大纲 / 确认 用户确认 → ReviewAgent自动评分 → 进入3
3剧本撰写 架构确认 大纲+角色+前集 WritingAgent(逐集)+ReviewAgent(逐集) 逐集剧本正文(表格+详情) 逐集查看/修改/通过 / 批量导出 全部集数通过 → 进入4
4质量审核 全部撰写完成 完整剧本 ReviewAgent(整体) 六维评分·问题列表·修改建议 查看评分/逐条处理问题 ≥85通过 / 70-84标注通过 / <70退回阶段3
5润色 审核通过 审核通过的剧本+修改建议 PolishAgent 对白优化·节奏调整·格式统一 逐集查看润色差异 / 接受/回退 用户确认 → 进入6
6资产提取 润色完成 定稿剧本 AssetAgent 角色资产·场景资产·道具·连续性台账 查看/补充资产信息 资产完整 → 进入7
7提示词生成 资产提取完成 资产+剧本 PromptAgent Seedance 2.0 提示词(每个关键场景) 查看/复制提示词 / 导出 全部提示词生成 → 项目完成
Ralph Loop 规则：每个阶段完成后 ReviewAgent 自动审核。评分≥85 直接通过；70-84 标注问题但通过；50-69 退回上一阶段重做；50 以下退回阶段1重新构思。最多循环3次，3次后标记「需人工介入」。
