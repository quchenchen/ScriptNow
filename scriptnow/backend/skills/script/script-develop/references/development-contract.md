# Screen story development contract

## Inputs

- User premise and protected material
- Medium and production form
- Language, audience, market, genre, tone, runtime or episode parameters
- Production constraints and selected narrative structure

Treat missing values as unknown. Do not silently invent product parameters.

## Candidate test

Each direction must make these differences visible:

1. Protagonist action and immediate lack
2. Opposing person, institution, environment, or rule
3. Repeatable scene engine
4. Relationship and emotional promise
5. Escalation mechanism
6. Moral choice and ending cost
7. Screen identity through image, space, behavior, object, and sound
8. Production implication

Reject alternatives that share the same causal chain and only change labels.

## Red lines

- No novel synopsis that depends on interior explanation.
- No theme statement without a dramatic choice.
- No automatic adoption.
- No fixed episode, scene, runtime, or budget assumptions not found in project facts.
