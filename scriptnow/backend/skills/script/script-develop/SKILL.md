# Develop a screen story

1. Preserve the user's medium, format, duration, audience, genre, and production constraints.
2. Generate alternatives with different dramatic engines rather than cosmetic premise changes.
3. Express each option through a filmable protagonist action, visible opposition, escalating consequence, and thematic choice.
4. Test whether the premise can repeatedly generate scenes and whether its visual identity survives without narration.
5. Recommend a direction with explicit creative and production trade-offs.
6. Submit the chosen direction as a Script-domain candidate only.
