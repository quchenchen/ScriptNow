# 短剧集末悬念设计

悬念不是"停在危险处"，而是"让观众明确知道下一集必须看什么"。本 Skill 覆盖集末悬念的类型、设计原则和分题材策略，继承 `script-cn-short-drama` 的单集闭环规则。

## 一、悬念必须来自本集主冲突

- 集末悬念必须是本集情节的自然延伸，不是从天而降的意外
- 如果删除本集前 80% 的内容，悬念仍然成立——那这个悬念不属于本集
- 悬念与开篇钩子形成呼应：开篇提问→中段发展→集末给出部分答案+抛出更大问题

## 二、四种悬念类型

| 类型 | 机制 | 示例 |
|------|------|------|
| **半兑现爽点** | 给了甜头但留了更大的 | 身份揭露了一半——对方震惊但还没完全相信 |
| **未完成问题** | 提出一个必须回答的新问题 | "你以为当年那场大火是意外？"——画面切黑 |
| **身份反转预告** | 暗示下一集将有重大身份揭露 | 主角摸向口袋里的令牌，镜头切到仇人正在靠近 |
| **危机升级** | 危险刚刚升级到更致命的程度 | 主角刚躲过追杀，回到安全屋——发现门开着 |

## 三、半兑现原则——不是"只吊胃口"

| 正确做法 | 错误做法 |
|---------|---------|
| 揭露一部分真相并让角色获得阶段性胜利，但揭示更大的幕后黑手 | 完全不给答案，每集都是"下集更精彩" |
| 情感关系前进一步但马上遇到新的外部压力 | 关系反复横跳无实质进展 |
| 敌人被打倒一个，但镜头切到更高层的敌人正在关注 | 敌人永远不倒下，只是换个马甲 |

**半兑现公式：** 达成一个小目标 + 发现达成的是更大目标的一小步 + 下一集必须面对的更大挑战

## 四、分题材悬念策略

| 题材 | 最强悬念类型 | 具体手法 |
|------|------------|---------|
| 复仇 | 身份反转预告 | 镜头切到下一个仇人看到主角真实身份的证据 |
| 女频甜虐 | 未完成问题（关系） | "如果我说当年的孩子还活着，你还会走吗？" |
| 男频逆袭 | 危机升级+身份揭露 | 更高层敌人出手+主角即将亮出更高身份 |
| 霸总 | 半兑现爽点（关系） | 霸总当众靠近女主，但家族代表突然出现 |
| 战神 | 危机升级 | 旧部集结完毕，但敌人先发制人偷袭了大本营 |
| 狼人 | 未完成问题（秘密） | 变身秘密即将暴露给最关键的人 |

## 五、下集承诺——不说"下集更精彩"但让观众知道为什么精彩

- 集末最后 3 秒必须给观众一个具体的"下一集要回答的问题"
- 用画面而不是台词传递承诺：一个特写/一个动作/一个表情
- 避免空洞承诺：不是"故事还在继续"而是"他即将发现那个改变一切的秘密"

## 六、常见错误

- 悬念与正文无关——悬念是正文的推论，不是附赠的预告片
- 每次同一类型悬念——复仇剧不能每集都是"身份即将揭露"
- 半兑现变零兑现——给了悬念就必须在 1-2 集内部分兑现
- 悬念密度过高——不是每一集都需要生死危机级别的悬念
