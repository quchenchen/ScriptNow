# 男频逆袭短剧 craft

逆袭的核心是"被全世界低估的人，让全世界跪下"。继承 `script-cn-short-drama` 的全局规则，本 Skill 定义男频逆袭类型的专属叙事机制。

## 一、逆袭四段式

| 阶段 | 核心 | 爽点类型 |
|------|------|---------|
| 羞辱开场 | 主角被当众羞辱、退婚、辞退、驱逐 | 积蓄怨恨（压） |
| 隐藏身份 | 主角拥有隐藏能力/身份但低调行事 | 小范围打脸（小放） |
| 逐步揭露 | 每揭露一层身份，碾压一批对手 | 中范围碾压（中放） |
| 终极归来 | 最高身份揭露，全面碾压幕后黑手 | 大范围清算（大放） |

## 二、敌人层级递进

```
小喽啰（混混/势利眼亲戚）→ 中层（竞争对手/反派手下）
    → 大人物（财阀/门派掌门）→ 幕后黑手（真正敌人）
```

**每层揭露更高身份**：主角先亮出"小身份"打脸小喽啰，再亮出"中身份"碾压中层，最后"终极身份"清算幕后黑手。

## 三、爽点密度要求

- **每 1-2 集至少一次小打脸/身份小揭露**——男频观众耐心极低
- 打脸必须有"观众"：被当众羞辱的效果远超私下解决
- "碾压"不是靠运气：主角展现的是碾压级实力差距，不是侥幸获胜

## 四、盟友体系

- 每 3-5 集收服一个关键盟友：武道高手、商界精英、医术圣手、情报大师
- 每个盟友有自己的故事线和归顺理由（不是工具人）
- 盟友集结的时刻是整季最大爽点之一

## 五、付费卡点

- 身份即将被揭露给最关键的见证者（前任/仇人/大人物）
- 敌人放出大招以为必胜，主角反杀的前一帧
- 一个更高级别的身份信物/令牌刚刚亮出，众人反应的前一刻

## 六、常见误用

- 打脸密度不够（超过 2 集无打脸 = 观众流失）
- 敌人太弱无挑战感（碾压需要对手先嚣张才有快感）
- 主角无敌化后失去成长空间（保留至少一个无法用武力解决的困境）
- 女性角色只做花瓶/奖品（至少一个女性角色有独立剧情线）
