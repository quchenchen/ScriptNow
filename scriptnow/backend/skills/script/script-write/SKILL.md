# 剧本写作

## 核心铁律

**1. 剧本只写摄影机和录音机能捕捉的内容。**

编剧不是小说家。小说家的工具是「揭示内心」，编剧的工具是「呈现可见的动作」。
任何一句 action，拿出来问「导演能不能拍？」——如果答案是「不能」，删除。

**2. 信息不是平等的。核心戏点必须被强调，氛围细节必须退让。**

AI 最容易犯的错误：把所有细节写在同一密度上，导致观众不知道应该关注什么。
一场戏里，最多一两个信息是「核心」，其余是「支撑」。核心信息必须用最锐利的工具交付。

**3. 对话不是最后手段——它是主要武器。**

「展示，不要告诉」不是说「永远不要用对话交代信息」。恰恰相反——
在关键戏剧节点上，对话是最直接、最锋利、最可控的工具。
用一连串动作/道具/环境细节去暗示一个核心信息，不如让角色一句话说出来，然后让接下来的行动去验证或推翻这句话。

---

## 一、信息层次：什么是核心戏点，什么是氛围

### 没有层次 = 失焦

```
❌ 错误：AI 把每一个细节都写得同样饱满

△ 清晨的阳光透过斑驳的窗棂洒进来，在木地板上投下细碎的光斑。
△ 她坐在床边，手指无意识地摩挲着被角。被角已经起了毛边。
△ 桌上摆着半杯凉掉的茶。窗外的鸟叫了三声。
△ 她起身。走到桌前。拿起杯子。看了一眼。放下。
△ 「该走了。」
→ 这段话里有信息吗？有。观众知道该关注什么吗？不知道。
```

### 有层次 = 观众知道该看哪里

```
✅ 正确：一个核心动作，其余是快速过渡

△ 她坐在床边。不动。
△ 门开了。她没抬头——但她知道谁进来了。
△ 她把一张存折推过桌面。
    「你的。」
    他盯着存折。没拿。
    「我不要钱。」
    她站起来。走到门口。停了一步——没回头。
    「我知道。」
→ 核心信息：「她用存折做了一件事，他拒绝了。」
   支持信息：「她猜到他会拒绝。」
   氛围信息：「她一整夜没睡」（通过「不动」「没抬头」暗示，不展开）
```

### 判断原则

在写每一场之前，先回答：**这场戏里，观众只需要记住哪一件事？**

```
✅ 八零后妈 5-1 的核心信息：司念用一句话揭穿刘婶的目的——「我嫁了你就失业」
   其余都是支撑：争论→铺垫→一个反击→定格

✅ 无双 2-1 的核心信息：楚青能调动南省最大的权力人物——「三分钟，南省除名」
   其余都是支撑：周麒炫耀→楚青无视→一个电话→验证
```

### 操作规则

1. 每场戏只设 **一个核心信息**。如果本场必须传达两个核心信息，拆成两场。
2. 核心信息用对话交付——因为对话是最可控的工具。
3. 氛围/过渡用动作快速带过——不要展开。一两个动作即可，不用写上三四行。
4. 写好核心信息后，回头删掉所有和核心信息抢注意力的冗余细节。

## 二、对话：你的主要武器，不是最后手段

### 错误观念：「用动作代替对话 = 高级」

这是 AI 最容易陷入的陷阱。它把「展示，不要告诉」误解为「禁止用对话交代信息」。
于是它用大量动作、道具、环境细节去暗示一个本可以用一句台词就说清楚的信息。
结果：信息被稀释在无数细节里，观众抓不住重点。

### 正确的判断：工具选择取决于信息的重要性

| 信息类型 | 用什么工具 | 为什么 |
|---------|-----------|--------|
| **核心戏点**（本场必须让观众知道的事） | **对话** | 直接、可控、不会被误解 |
| 关系/权力状态 | 对话 + 动作验证 | 对话摆出筹码，动作证明真假 |
| 情绪底色 | 动作 | 动作比台词更诚实 |
| 氛围/环境/过渡 | 动作 | 快速带过，不要展开 |
| 前史（观众需要知道的过去） | 对话——从冲突中漏出来 | 不单独交代，让角色在吵架/谈判/试探时顺便说 |

### 参考案例：对话作为核心武器

```
「八零后妈」5-1：
刘婶和大娘争吵了六七句——关于彩礼、身份、该不该进门。
都没有解决核心问题。
司念一句：「如果我嫁给周越深啊，肯定我带孩子，她就等于丢了工作，
          可不着急赶我走嘛。」
一句话拆穿了刘婶的所有伪装。局势立即翻转。

→ 前面的争吵是铺垫，这句台词是核心武器。
  核心信息永远用对话——最锋利、最精准。
```

```
「无双」2-1：
周麒长篇大论炫耀森爷的权势——六七句。
楚青一句：「通知任城森，三分钟内，到海城西郊档口来见我。
          若逾时不到，任家，南省除名。」
一句话摧毁了周麒的全部底气。下一场立刻验证。

→ 敌人的长篇是铺垫，主角的一句是核心武器。
  铺垫可以啰嗦——因为观众的注意力在等主角的反击。
  核心武器必须简短、可验证、有后果。
```

### 操作规则

1. **需要观众记住的信息 → 用对话。** 动作可以辅助，但核心信息必须从角色的嘴里说出来。
2. **对话写完 → 让动作去验证或推翻。** 角色说「我不在乎」→ 下一个动作是偷偷看了一眼。对话和动作互相检验，不是互相替代。
3. **铺垫可以长，核心必须短。** 对手的啰嗦是铺垫——让观众积累期待。主角的反击必须精炼——一句见血。
4. **禁止用一连串动作去「暗示」一个本可以用对话说清楚的关键信息。** 这不是高级——这是模糊。

## 三、视听语言对照表

### 编剧可以写的：动作、表情、位置、声音、节奏

**身体动作**（直接可见）
```
✅ 余国伟穿过人群跑向李警官。
✅ 他推开门。门轴嘎吱一声。
✅ 她把箱子拖到门口。太重——停了一下，换了只手。
```

**面部表情**（用直述词，不用隐喻）
```
✅ 皱眉。微笑。阴沉。惊。呆滞。狞笑。
✅ 唐万财一脸得意。
✅ 贺敛双目猩红，紧紧盯着她。
❌ 眼神里闪过一丝不易察觉的忧伤。（隐喻）
❌ 嘴角扬起一个若有若无的弧度。（文学修辞）
```

**位置与空间**
```
✅ 他走到她对面坐下。
✅ 两个人隔着一张桌子。桌上的杯子谁都没碰。
```

**声音**
```
✅ 筷子搁在碗沿——啪的一声。
✅ 手机铃声响了。她没接。铃声停了。又响了。
```

**动作的节奏/速度/力度**
```
✅ 他疾步向前走去。
✅ 她把杯子放下——动作很慢。
✅ 她继续切菜，刀刃落得比刚才重。
```

### 编剧不能写的：心理、隐喻、抽象、判断、触觉嗅觉

| 禁止类别 | 禁用词/模式 | 为什么 |
|----------|-----------|--------|
| 心理活动 | 心想、感到、内心、回忆、情绪、心情、意识 | 摄影机拍不到 |
| 身体隐喻 | 骨节发白、指甲掐进掌心、指尖泛白、喉头发紧 | 文学修辞，不是直接动作 |
| 抽象氛围 | 气氛紧张、命运、宿命、人生、时光、岁月 | 没有给出具体画面 |
| 概括形容词 | 精致、优雅、奢华、华丽、简陋 | 没有给出具体视觉元素 |
| 机械钩子 | 「他不知道…」「殊不知…」「命运的齿轮…」 | 面向读者，不是拍摄 |
| 情绪宣告对白 | 「我恨你」「我好痛苦」「太可怕了」 | 人物宣布情绪 = 偷懒 |
| **触觉嗅觉** | 温温的、发麻、冰凉、刺痛、柔软、粗糙、闻到、气味 | 摄影机录音机拍不到 |

## 四、「戏」——场景必须有事件

白描不是戏。戏 = 事件 + 冲突 + 转折 + 后果。

```
❌ 无事件：「清晨，她坐在纺织机前，木轴转着，车间里光线昏暗。」
   → 白描了环境和状态，什么都没有发生。

✅ 有事件：「她把一叠订单塞进继母手里。继母翻了两页——脸色变了。
   她站着没走，等继母把每一页都看完。」
   → 有人做了动作，局面发生了变化。
```

每场必须具备：冲突、升级、转折、后果。

## 五、场景创作流程

**第 1 步**：从 StoryMap 读取功能——本场唯一不可替代的事是什么？

**第 2 步**：确定核心信息——观众只需要记住哪一件事？

**第 3 步**：选择工具——核心信息用对话，氛围用动作快速带过。

**第 4 步**：写核心对话——一句或一组对话，直接命中核心信息。铺垫可以展开，核心必须锐利。

**第 5 步**：用动作支撑——验证或推翻角色说的。不要用动作替代对话去暗示关键信息。

**第 6 步**：砍掉冗余——回头删掉所有和核心信息抢注意力的细节。
