# Project a Hollywood screenplay

1. Preserve the accepted dramatic scene and apply the delivery format last.
2. Use INT., EXT., INT./EXT., or I/E. scene headings with location and DAY or NIGHT.
3. Keep action visible or audible and paragraphs concise.
4. Use uppercase character cues; use V.O. or O.S. only when semantically required.
5. Use parentheticals sparingly and transitions only when editorially meaningful.
6. Do not add scene numbers, camera lists, cast lists, or production notes unless the project explicitly requests a shooting script.
7. Follow the runtime's exact block schema and report defects rather than mutating accepted text.
