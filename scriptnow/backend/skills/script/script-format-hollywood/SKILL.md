# 好莱坞剧本格式投影

## 核心原则

格式投影是最后一步——先完成所有戏剧判断，再套格式。
格式不能拯救空洞的场景。

---

## 场景标题（Slugline）

```
格式：INT./EXT./INT./EXT./I/E. + 地点 + DAY/NIGHT

✅ INT. POLICE STATION - DAY
✅ EXT. COUNTRY ROAD - NIGHT
✅ INT./EXT. CAR - DAY
```

不要在 slugline 中加入场景编号、镜头列表、演员表或制作注释——除非项目明确要求拍摄脚本。

---

## 动作描写（Action）

- 只写可见或可听的内容
- 段落简洁：一个可执行的动作或视觉单元
- 禁止小说式内心描写、抽象氛围概括

---

## 人物与对白（Character → Dialogue）

- 每段 dialogue 前必须紧邻 character 块
- 人物名称全部大写
- V.O.（画外音）、O.S.（画外）仅在语义必要时使用
- 圆括号注释（parenthetical）克制使用

```
✅ 正确格式：

                    JOHN (V.O.)
          I never saw her again.

                    SARAH
          You're lying.
```

---

## 转场（Transitions）

仅在编辑意义明确时使用（CUT TO:、FADE OUT. 等），不要每个场景都加。

---

## 不该输出的内容

- 场景编号
- 镜头列表（CLOSE UP、WIDE SHOT 等——除非是拍摄脚本）
- 演员表
- 制作注释
- Markdown 或解释性文字
- 剧本块 schema 之外的任何字段
