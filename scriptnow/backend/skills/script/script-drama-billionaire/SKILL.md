# 霸总短剧 craft

霸总的核心是"全世界的规则对他无效，只有你例外"。继承 `script-cn-short-drama` 和 `script-drama-romance` 的通用规则，本 Skill 定义霸总类型的专属叙事机制。

## 一、关系六段弧线

| 阶段 | 核心事件 | 情绪方向 |
|------|---------|---------|
| 契约建立 | 因利益/家族/意外签订契约（婚姻/恋爱/同居） | 中立 |
| 日常相处 | 被迫同居/共事中产生真感情 | 小放 |
| 外部压力 | 家族反对/商业对手/前任出现迫使分离 | 压 |
| 被迫分离 | 一方为保护另一方而主动离开 | 大压 |
| 双方觉醒 | 意识到对方是不可替代的 | 小放 |
| 重新选择 | 放弃利益/身份/家族期望，选择彼此 | 大放 |

## 二、霸总人设法则

- **"只对你破例"是核心卖点**：对所有人冷酷高效，只对女主露出软肋
- **关键时刻出手保护**：女主遇到麻烦时，霸总用资源/权势碾压式解决——这是核心爽点
- **表面控制欲 ≠ 不尊重**：控制欲源于保护欲，不是占有欲
- **必须有脆弱面**：童年的创伤/家族的责任/不可言说的秘密——让人物立体

## 三、契约婚姻的独特节奏

1. **契约是"安全的距离"**：两人以契约之名靠近，但契约本身是感情的最大障碍
2. **"假戏真做"的节奏**：每 3-5 集一次"契约测试"——看似在履行契约，实则真心流露
3. **契约暴露是最大转折**：约第 12-15 集，契约真相被曝光，两人关系跌至谷底
4. **重新选择高于契约**：结局时，两人在没有契约约束下仍然选择彼此

## 四、付费卡点

- 霸总当众宣布"她是我的人"的前一刻
- 契约真相即将被对方发现的关键瞬间
- 家族施压逼迫分开，霸总必须在家族和爱情之间做选择
- 女主决定离开，霸总追到机场/车站的最后一面

## 五、常见误用

- 霸总"霸道"变成"不尊重人"——命令和控制必须有保护欲作为支撑
- 女主无独立人格——必须有除了爱情之外的目标和成长线
- 每集重复"误会→吃醋→和好"套路——需要外部冲突升级来推进
- 豪门背景只做摆设——需要展现家族/商业压力的具体影响
