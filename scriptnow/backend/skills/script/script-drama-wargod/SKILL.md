# 战神归来短剧 craft

战神归来的核心是"那个被你们看不起的人，是你们惹不起的存在"。继承 `script-cn-short-drama` 和 `script-drama-counterattack` 的通用规则，本 Skill 定义战神类型的专属叙事机制。

## 一、归来四段式

| 阶段 | 集数 | 核心 | 情绪 |
|------|------|------|------|
| 蛰伏 | 第 1-3 集 | 亲人/爱人受辱，战神低调隐忍，暗中观察 | 压 |
| 试探 | 第 4-7 集 | 小范围出手但隐藏身份，旧部开始察觉 | 小放 |
| 震慑 | 第 8-15 集 | 令牌/信物亮出，旧部集结，敌人从轻蔑到恐惧 | 中大放 |
| 王者归来 | 第 16-20 集 | 全面归来，清算所有仇敌，守护想守护的人 | 大放 |

## 二、身份揭露的递进节奏

```
线索（旧伤疤/特殊习惯/无名指戒指）→ 信物（令牌/徽章/戒指）
    → 旧部认出（某个老战友震惊跪拜）→ 敌人确认（对方从嘲笑到跪下）
        → 全面归来（所有旧部集结，战神之名响彻）
```

**每层揭露都需要"观众"**：揭露给越关键的人看（仇人/爱人/背叛者），爽感越强。

## 三、压场对白公式

战神对白的特点是"少即是多"——三个字能震慑就不说五个字：

| 公式 | 示例 |
|------|------|
| 简短宣告 | "他是我的人。" "滚。" "你不配。" |
| 反问碾压 | "你知道这块令牌代表什么吗？" |
| 沉默震慑 | 不说话，缓缓亮出信物，镜头切众人震惊表情 |

**关键原则**：台词越来越短，眼神越来越冷，对方从轻蔑→疑惑→震惊→恐惧的完整表情转变。

## 四、情感核心

- **归来目的不是炫技**：是守护家人/为战友复仇/赎回当年的过错
- **必须有"软肋"**：那个让他脱下战甲的人——爱人/母亲/女儿
- **归来 ≠ 回到过去**：战争留下的伤痕（身体/心理）是人物深度
- **"为你，我愿意再做一次战神"** ——这是最强情感付费点

## 五、付费卡点

- 战神即将出手但被爱人阻止的瞬间
- 令牌/信物即将被当众亮出，众人还在嘲笑的前一秒
- 旧部集结完毕，战神站在最前方，敌人还不知道面对的是谁
- 爱人遇到致命危险，战神必须暴露身份的抉择时刻

## 六、常见误用

- 战神无敌化——需要至少一个无法用武力解决的困境（亲情/道德/规则）
- 每集同一模式亮身份——需要用不同方式、不同场合、不同见证者
- 女性角色只做被保护对象——至少一个女性角色有独立行动和决策
- 归来后无代价——退役战神回归普通生活必然有适应之痛
