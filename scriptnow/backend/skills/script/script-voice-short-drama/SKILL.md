# 竖屏短剧类型语感指南

## 为什么需要这份指南

竖屏短剧不是「缩短的电影剧本」。不同目标受众的短剧有完全不同的：
- 对白节奏（女频 3 句推进关系 vs 男频 1 句碾压对手）
- 冲突密度（每集 1-2 分钟必须有一个小高潮/反转/钩子）
- 情绪载体（女频靠细节动作 + 特写 vs 男频靠行动后果）
- 台词策略（女频试探 → 拉锯 → 反杀 vs 男频挑衅 → 碾压 → 验证）

不区分类型的剧本，角色全员同腔，对白可以互换——这是 major 缺陷。

---

## 一、女频短剧

### 核心引擎

关系变化——权力、信任、情感、身份的关系博弈。

### 参考范例

以下片段来自《我在八零年代当后妈》，展示女频短剧的核心特征：

```
△ 司念提着两个大箱子从卧室走了出来，刘思思偷偷用余光瞥了一眼。

刘思思：念念姐，这件事情都怪我，你可千万别怪爸妈。你要是生气的话……
      你要不，打我两下出出气？

司念：（扇了刘思思一巴掌）行嘞！

△ 刘思思被打蒙，定格。
```

**为什么这段是好的**：
1. 冲突来自具体行动（打耳光），不是空洞宣告
2. 刘思思台词表面示弱、里层道德绑架——潜台词清晰
3. 司念用一个行动（真打）同时完成反击 + 表态 + 推进节奏
4. 定格收尾——一分钟内的情绪爆点

### 对白策略

女频对白是**博弈语言**，不是信息交换：

```
试探 → 接招 → 反拉 → 推拉 → 破局

✅ 「念念姐，这件事情都怪我。」（表面道歉，里层道德绑架）
✅ 「按你这么说，我儿子是鲤鱼，那我是什么？」（用对方的逻辑反打）
✅ 「你替思思享了十八年的福，思思呢，替你受了18年的苦！」（以退为进的道德压）
```

**禁止**：
- 人物直接宣布情绪（「我好伤心」「我恨你」）
- 直白解释剧情（「你知道吗，我已经看穿你的计划了」）
- 寒暄水词（「你好吗」「今天天气不错」）

### 情绪外化

女频的情绪不靠台词宣示，靠**细节动作**：

```
✅ 捏紧裙角 → 松开 → 指甲在掌心掐出印子
✅ 夹菜的手停在空中一瞬 → 继续夹，动作比刚才轻
✅ 转过头时先垂眼，再抬眼
✅ 嘴唇动了动，没说出口

❌ 「她内心感到一阵酸楚」
❌ 「她的眼神里充满了复杂的情绪」
```

### 节奏特征

- 每集至少一个关系位面的翻转（信任崩塌 / 权力逆转 / 秘密泄露）
- 关键情绪节点用【特写】标注
- 对白句长变化丰富：短句（一个词）→ 中句（15-25 字）→ 长句（30+ 字）交替
- 落点在人物反应上，不在事件交代上

### 参考剧本中的典型节奏

《乖乖入局》第一集：
```
起：姜郁算计贺敛（性张力开场）
承：宋家内部冲突（姜郁装疯 vs 宋雪妍傲慢）
转：贺敛发现自己被算计（怒气 + 困惑）
合：姜郁再次蓄意接近（钩子——贺敛上钩了）
```

## 二、男频短剧

### 核心引擎

身份落差与力量逆转——被轻视者亮出真实身份后的碾压快感。

### 参考范例

以下片段来自《无双》，展示男频短剧的核心特征：

```
周麒（阴沉）：小子，你惹了我，尚有活路。但森爷他盘踞南省大半世纪有余，
      权势通天……敢对他老人家不敬，这南省，可没人能护得了你。

楚青：就是他任城森站在这，又能奈我何？

△ 楚青抬起手机。

楚青：三分钟。通知任城森，三分钟内，到海城西郊档口来见我。
      若逾时不到，任家，南省除名。
```

**为什么这段是好的**：
1. 周麒长篇炫耀靠山 → 楚青一句话摧毁——典型的碾压结构
2. 对话节奏：对手长 → 主角短，信息密度呈倒金字塔
3. 「三分钟」「南省除名」——具体、可验证、有后果的宣告
4. 每个角色有自己的措辞层级（周麒吹捧靠山 vs 楚青直接调令）

### 对白策略

男频对白是**权力对抗语言**：

```
挑衅 → 亮底牌 → 碾压 → 验证后果

✅ 「好大的口气！」（挑衅）
✅ 「那就是任城森站在这，又能奈我何？」（亮底牌——透露与更高权力的关系）
✅ 「三分钟。逾时不到，南省除名。」（碾压——具体威胁 + 具体时限）
✅ 「通知他。告诉他，海城西郊，楚青在等他。」（验证——给出验证方式）
```

**禁止**：
- 主角长篇解释自己的身份（靠行动和第三方反应来证明）
- 对手空洞放狠话（每句威胁要可验证、有具体后果）
- 打斗前的嘴炮过长（3 句内必须动手或翻转）

### 行动描写

男频短剧的 action 必须写清动作的**落点与后果**：

```
✅ 楚青反手卸下器械，锁住打手胳膊。打手吃痛——胳膊已经卸了。
✅ 他抬脚碾碎倒扣的餐盘，踩在烤串上。

❌ 他轻松击败了对手。（没写怎么击败的）
❌ 打斗非常激烈。（没写具体动作）
```

### 节奏特征

- 每集至少一个权力翻转（从被轻视到碾压）
- 信息差驱动：观众知道主角真实身份，反派不知道——这是核心爽感来源
- 对话密度：一句推进、一句碾压、一句钩子去下一集
- 结尾通常是新的挑衅或更大的冲突被激活

## 三、甜宠/霸总短剧

### 核心引擎

权力差 + 身体语言 + 性张力——不是「谈恋爱」，是权力不对等下的吸引与征服。

### 参考范例

以下片段来自《乖乖入局》：

```
△ 贺敛握住姜郁的手腕用力往前拽了一下。

贺敛（咬牙切齿）：你他妈到底是谁？

△ 姜郁眸光木讷，另一只手机械般地按在贺敛起伏的胸肌上，
  随后靠近亲吻他的胸肌。

△ 贺敛轻哼一声，喉结滚动。

△ 姜郁似是不解，仰头看着贺敛。

贺敛（嗓音低哑）：傻子？
```

**为什么这段是好的**：
1. 情绪不靠台词宣示——喉结滚动、嗓音变化传递生理反应
2. 权力差：贺敛居高临下审问 vs 姜郁用身体行动反制
3. 【特写】标记关键身体语言落点
4. 对话极简——愤怒和欲望都从身体透出来

### 视觉语言密度

霸总类剧本的视觉密度远高于一般短剧：

```
✅ 【特写：姜郁亲吻贺敛胸肌】
✅ 【特写：闪电照亮姜郁的脸庞】
✅ 【特写：衣衫落地】
✅ （慢镜头）贺敛握住姜郁的手腕用力往前拽
✅ （中全景—侧拍）姜郁呆头呆脑的仰头望向贺敛
```

### 对白策略

霸总对白的特点是**极简 + 攻击性 + 身体化**：

```
✅ 「手……别乱动。」（命令 + 身体边界）
✅ 「上我的床，就以为我会负责？」（挑衅 + 权力声明）
✅ 「傻子？」（两个字，表达了轻视、困惑、被吸引的复杂）

❌ 「你为什么要接近我？你到底有什么目的？」
   （太过直白，霸总不会这么问——他会用行动试探）
```

### 节奏特征

- 密集体感互动：每集至少一次身体接触/靠近/触碰
- 权力游戏：推拉、拒绝、反制——一个回合接一个回合
- 每集结尾落在关系状态变化上（靠近了 / 推远了 / 秘密被发现了）
- 【特写】密度是女频短剧的 1.5-2 倍

## 四、叙事节奏与信息密度（新增）

### 短剧的信息交付铁律

短剧每集 1-2 分钟。没有时间让观众「品味氛围」——每一秒都在传递信息或推进情绪。
以下模式是所有成功短剧的共同特征：

### 4.1 核心信息用对话，氛围用动作

```
✅ 正确的信息工具分配：

核心戏点（观众必须知道的）     → 对话——直接、锋利
关系/权力状态                    → 对话摆筹码 + 动作验证
情绪底色                         → 动作（比台词诚实）
前史（需要交代的过去）           → 对话——从冲突中漏出，不单独交代
氛围/过渡                        → 动作——一两个即可，不展开
```

### 4.2 每集的叙事密度

```
第一分钟（30-60 秒）：
- 开场钩子：一个动作或一句台词，让观众停下滑动
- 快速建立冲突：谁对谁、为了什么
- 信息集中在对话上——不要用动作暗示关键信息

中间段落（30-40 秒）：
- 冲突升级：新信息、新威胁、新选择
- 铺垫可以展开，但核心必须锐利

最后 10-15 秒：
- 反击或翻转——一句见血
- 钩子去下一集——不可逆的悬念
```

### 4.3 「铺垫 + 核心反击」的黄金比例

```
✅ 八零后妈 5-1：
   刘婶 + 大娘铺垫 6 句 → 司念反击 1 句
   比例：6:1
   效果：铺垫充分积累期待，核心一击致命

✅ 无双 2-1：
   周麒炫耀 7 句 → 楚青反击 1 句 + 电话验证 1 句
   比例：7:2
   效果：反派的啰嗦是铺垫，主角的精炼是力量

❌ AI 常犯错误：
   铺垫和核心反击写在同一密度、同一长度
   读者无法分辨重点在哪里
```

### 4.4 禁止「动作堆砌式暗示」

当核心信息被稀释在一连串动作中时，观众需要「解读」——而竖屏短剧观众不会解读。

```
❌ 她用一连串动作暗示她决定离开：
   收拾行李。看了一眼照片。摸了摸门框。
   最后看了一眼窗外的树。慢慢走到门口。回头。又转回去。
   → 6 个动作暗示一个信息。观众不知道什么重要。

✅ 「我走了。」
   她把钥匙放在桌上。
   门关上了。
   → 核心信息用对话交付。两个动作验证后果。
```

## 五、类型越界判定

当产出出现以下情况时，判定为类型越界（major）：

| 越界类型 | 症状 | 示例 |
|---------|------|------|
| 女频 → 男频化 | 女主角用碾压式宣告、身份亮牌来解决冲突 | 「其实我是首富的女儿」——女频的关系博弈不会这样解决 |
| 男频 → 女频化 | 男主角长篇分析情感、解释关系 | 「你知道吗，我这么做都是因为……」——男频男主不解释动机 |
| 霸总 → 普通恋爱 | 对白变成日常聊天、寒暄、商量 | 「你觉得这件衣服怎么样？」——霸总不商量 |
| 任何类型 → AI 味 | 角色全员同腔、对白可互换 | 遮住角色名后，无法分辨谁在说话 |
