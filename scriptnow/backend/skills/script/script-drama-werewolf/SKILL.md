# 狼人短剧 craft

狼人短剧的核心是"兽性与人性在你身上交战，而她是唯一的平衡点"。继承 `script-cn-short-drama` 的全局规则，本 Skill 定义狼人/超自然类型的专属叙事机制。

## 一、世界观基础

| 元素 | 具体设定方向 |
|------|------------|
| 月圆之夜 | 力量最强但理性最弱——是危机也是浪漫（"月下只有你懂我"） |
| 血统等级 | Alpha/Beta/Omega 或纯血/混血/觉醒——阶层冲突的自然载体 |
| 族群领地 | 不同狼群争夺领地——政治冲突的舞台 |
| 人类社会伪装 | 隐藏身份的日常紧张感——被发现=毁灭 |

## 二、感情线五段弧线

| 阶段 | 核心事件 | 张力来源 |
|------|---------|---------|
| 命定羁绊觉醒 | 第一次相遇时本能识别对方是"命定伴侣" | 抗拒 vs 吸引 |
| 被迫靠近 | 外部事件迫使两人在一起（危险/任务/族群命令） | 理性 vs 本能 |
| 试探与拉扯 | 在接纳与推开之间反复 | 保护欲 vs 伤害风险 |
| 接纳羁绊 | 承认感情但也承担随之而来的代价 | 甜蜜 vs 危机 |
| 共同面对威胁 | 族群战争/猎人追杀/血统危机 | 生死 vs 相守 |

## 三、独特的双重张力

**兽性 vs 人性**：
- 愤怒时眼睛变色/体温升高——外在表现内在挣扎
- "我怕伤害你"是核心情感冲突——保护欲与自我厌恶并存
- 变身场景是视觉高潮：骨骼重组、兽性释放、在最后关头因"她"而恢复人形

**保护欲 vs 伤害风险**：
- "我离你越近，你越危险"——每集都要体现这层矛盾
- 在月圆之夜/愤怒之时控制自己需要意志力——失败则伤害爱人
- 最终的告白是："我能控制体内的野兽，因为我更怕失去你"

## 四、关键视觉记忆点

- 月圆之夜（每月一次的仪式感场景）
- 眼睛变色（琥珀/金色→危险信号）
- 体温变化（触摸时异常的温度——亲密的、危险的）
- 嗅觉追踪（"我能在人群中闻到你的气息"——浪漫而动物性的）
- 变身过程（骨骼变形、毛发显现、从痛苦到力量释放）

## 五、付费卡点

- 变身秘密即将在普通人面前暴露的前一刻
- 命定羁绊被族群长老强行分离的关键决定
- 月圆之夜，他快要失控，她选择留下的最后一眼
- 族群战争一触即发，主角必须在族群和爱人之间做选择

## 六、常见误用

- 狼人设定只做噱头——超自然元素必须驱动剧情，不是装饰
- 变身场景滥用——每次变身都应该是情绪高潮，不是常规操作
- 女方角色被动化——在超自然世界中人也可以有力量（猎人后代/特殊血脉/知识力量）
- 族群政治过于复杂——短剧要求简洁，最多 2-3 个族群
