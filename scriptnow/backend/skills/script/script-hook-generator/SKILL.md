# 短剧钩子生成器

钩子不是"把精彩片段提前"——它是对观众注意力的投资：用最小的信息量撬动最大的好奇心缺口。每一集都必须回答一个问题：为什么观众要停下滑动的手指？

## 一、开场钩子设计（前 3-5 秒）

开场钩子是整集的生命线，必须在观众决定划走之前完成"认知触发"：

| 类型 | 机制 | 示例场景 |
|---|---|---|
| 身份危机 | 暴露角色身份与当前处境之间的矛盾 | 总裁被当成保洁员推上颁奖台 |
| 情感冲突 | 用一段关系的变化瞬间制造张力 | 未婚夫搂着闺蜜走进婚礼现场 |
| 意外事件 | 一个打破角色预期的事件突然发生 | 车祸后醒来发现自己躺在仇人床上 |
| 视觉冲击 | 用画面本身制造强烈感官刺激 | 坠楼瞬间、血泊中的婚戒、碎裂的全家福 |

**选择原则**：钩子必须指向本集核心矛盾，不能是孤立的花活。开场抛出问题 → 中段深化问题 → 结尾部分回答并抛出新问题，形成闭环。

## 二、中段升级（30-45 秒）

中段不是"过渡"而是"加速"。三种升级路径：

1. **冲突深化**：把开场的对抗从表面推向不可逆。嘲讽变羞辱，猜疑变背叛，对抗变决裂。
2. **秘密揭露**：向观众（但不必向角色）揭示一个改变信息格局的真相。
3. **筹码加码**：把风险从"丢面子"升级到"丢命""丢一切"。每加一次筹码，观众的心就悬一次。

**节奏要点**：中段情绪曲线必须是单向的——要么持续压低，要么持续拉高，不要在中段反复震荡。压抑的尽头是卡点的预备姿势。

## 三、付费点（卡点）设计

付费点不是"故事讲到这里"，而是"最想知道答案的时候停下来"：

- **身份反转**：角色真实身份即将暴露的前一帧
- **关系变化**：一段关键关系的性质即将被重新定义
- **信息差**：观众知道但剧中角色不知道的关键信息即将交汇
- **危机升级**：危险即将降临但角色尚未察觉
- **未完成承诺**：一个刚刚做出的承诺面临被打破的临界点

卡点必须落在"问题已经提出、答案即将揭晓"的缝隙——不能太早（答案还没出现），不能太晚（已经给了答案）。

## 四、集末桥接（下一集必须回答什么）

结尾不只是挂悬念，而是"签订一份契约"——明文承诺下一集要回答什么：

| 桥接类型 | 公式 | 示例 |
|---|---|---|
| 身份桥接 | 他/她到底是什么人？ | "你以为我是谁？"——说完这句话，画面定格 |
| 关系桥接 | 这段关系将走向何处？ | 他掏出了戒指——门被推开 |
| 命运桥接 | 角色能否逃脱/成功？ | 刀落下之前——时间凝固 |
| 信息桥接 | 那个秘密到底是什么？ | 她打开信封，表情骤变——画面切黑 |

**铁律**：下一集开篇第一句话必须回应这个桥接，不能跳时间线或换场景绕开。

## 五、钩子类型库

| 类型 | 适用场景 | 强度 |
|---|---|---|
| 身份揭露钩 | 隐藏身份类（总裁/神医/战神/大佬归来） | ★★★★★ |
| 关系危机钩 | 情感线/宫斗/家庭伦理 | ★★★★ |
| 生死悬念钩 | 悬疑/犯罪/末世/冒险 | ★★★★★ |
| 财富诱惑钩 | 都市/商战/逆袭/赘婿 | ★★★★ |
| 复仇预告钩 | 复仇主线 | ★★★★★ |

**混合使用**：同一部剧交替使用不同类型，避免观众免疫。建议每 3-5 集轮换钩子类型。

## 六、常见失败模式

| 问题 | 表现 | 修正 |
|---|---|---|
| 钩子与正文无关 | 开场扔一个爆炸信息，然后跳回三天前慢慢讲 | 钩子从中段提取，不凭空捏造 |
| 硬切卡点 | 对话说到一半强行断，无因果 | 卡点必须在"问题已成立"之后，而非"句子没说完" |
| 每次同一类型 | 每集都是"门被推开，她愣住了" | 建立钩子轮换表，四集一个周期 |
| 钩子力度递减 | 前期大场面用完，后期平淡 | 钩子强度必须随剧情发展逐步升级 |
| 桥接承诺不兑现 | 上一集留的悬念下一集忘了 | 每集开篇先还上一集的债，再讲新的 |
