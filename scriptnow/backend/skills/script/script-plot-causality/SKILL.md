# 情节因果链强制验证

短剧不是"然后发生了什么事"，而是"因为 A 所以 B，但是 C，因此 D"。每一个情节节点都必须有可追溯的原因、可度量的后果、可观察的角色反应。

---

## 一、事件因果三要素（每个情节事件的强制字段）

任何一个情节事件（含反转、揭露、冲突、决策、行动），必须同时具备以下三个要素。缺任意一个，该事件视为悬浮事件，需重写或删除。

| 要素 | 定义 | 检验问题 | 反例 |
|------|------|---------|------|
| **前因（Cause）** | 该事件为何必然发生——驱动它的前置事件或角色决策 | "如果没有 X，这件事还会发生吗？" | "突然，一群黑衣人冲了进来"——没有任何铺垫 |
| **后果（Consequence）** | 该事件改变了什么——关系、信息、权力、风险、目标中至少一项 | "这件事发生后，什么和之前不一样了？" | 打了一架、所有人都散了，剧情回到原点 |
| **角色反应（Character Reaction）** | 情感判断 + 行为决策——角色如何理解这件事并做出了什么选择 | "角色此刻感受到了什么？他/她接下来决定做什么？" | 主角面无表情地接受了所有信息，然后继续原计划 |

### 因果三要素映射表（每集核心事件填写）

```
| 集数 | 事件         | 前因（哪个前置事件/决策驱动） | 后果（改变了什么）       | 角色反应（情感+行为） |
|------|------------|---------------------------|-----------------------|---------------------|
| 1    | 女主被当众羞辱 | 恶毒女配嫉妒女主与霸总的接触  | 女主社交处境恶化，霸总注意到她 | 屈辱但倔强：决定靠自己翻身 |
| 2    | 霸总当众护女主  | 第1集霸总注意到女主受辱       | 女主社会地位上升，女配仇恨升级 | 意外+警惕：拒绝霸总好意 |
| ...  |            |                           |                       |                     |
```

## 二、因果链回溯验证（从高潮倒推至激励事件）

规划阶段完成全剧大纲后，必须执行一次"因果链回溯"——从高潮事件开始，逐级追问"为什么会发生这个？"，一直追溯到激励事件。任何无法回答"为什么"的节点即为因果断裂。

### 回溯步骤

```
高潮事件（第 N 集）
  ↑ 为什么发生？
  直接前置事件 A
    ↑ 为什么发生？
    前置事件 B
      ↑ 为什么发生？
      ...
        ↑ 为什么发生？
        激励事件（第 1-3 集）
```

### 回溯检验记录表

```
| 回溯层级 | 事件              | 前因事件           | 因果逻辑是否成立 | 备注 |
|---------|------------------|------------------|----------------|------|
| 1       | 最终对决           | 主角集结所有盟友    | ✓ / ✗          |      |
| 2       | 集结盟友           | 主角发现敌人真正身份  | ✓ / ✗          |      |
| 3       | 发现敌人身份        | 关键线索在中期揭露    | ✓ / ✗          |      |
| ...     |                  |                  |                |      |
| N       | 激励事件           | —                | 起点             |      |
```

**铁律**：如果回溯路径中出现"莫名其妙"、"恰好"、"运气的安排"作为回答，则该节点因果断裂。

## 三、巧合预算（Coincidence Budget）

巧合天然破坏因果链。但短剧篇幅有限，完全禁止巧合不现实。因此设定预算——超预算即违规。

### 核心规则

| 规则 | 内容 |
|------|------|
| **总额度** | 全剧每 5 集最多允许 1 个巧合事件（20 集短剧最多 4 个巧合） |
| **只能用巧合制造麻烦** | 巧合只能让主角处境更糟或引入新障碍——绝不能解决危机或提供关键帮助 |
| **巧合必须付出代价** | 因巧合获得的信息或资源，必须在 1-2 集内被角色用决策和代价"偿还" |
| **关键转折禁巧合** | 高潮反转、终极对决的胜负、主角身份揭露的关键证据：**零容忍巧合** |

### 巧合分类与判定

| 类型 | 允许？ | 示例 | 说明 |
|------|-------|------|------|
| 制造麻烦的巧合 | ✅（计额度） | 主角逃到小巷尽头——恰好是仇人的地盘 | 恶化处境，推动新冲突 |
| 解决问题的巧合 | ❌ | 主角被围困，恰好警察路过救了所有人 | 降神（Deus Ex Machina） |
| 信息获取的巧合 | ⚠️（计额度+需偿还） | 恰好偷听到关键对话 | 必须在后 1-2 集中用角色主动决策验证并付出代价 |
| 人物相遇的巧合 | ⚠️（计额度+需偿还） | 两个关键角色在机场偶遇 | 必须在后续用"他们为什么必然相遇"的解释合理化 |

### 巧合使用登记表

```
| 集数 | 巧合事件              | 类型           | 制造麻烦/解决问题 | 偿还方式与集数    | 剩余额度 |
|------|---------------------|---------------|-----------------|-----------------|---------|
| 3    | 女主躲雨恰好进霸总公司 | 人物相遇巧合    | 制造麻烦         | 第 4 集：女主用能力证明自己 | 3/4 |
|      |                     |               |                 |                 |         |
```

## 四、角色决策驱动——不要"情节推着角色走"

短剧的每一次重大转折必须由**角色的主动选择**驱动，不能由外部事件单方面推动。

### 角色决策 vs 情节便利对照表

| 正确（角色驱动） | 错误（情节便利） |
|----------------|----------------|
| 女主得知真相后，**主动选择**去揭露仇人，尽管这意味着暴露自己身份 | 女主刚要揭露仇人，仇人**恰好**自己说漏了嘴 |
| 男主看到女主被欺负，**压抑愤怒权衡利弊后**决定出手 | 男主**刚好赶到**现场，正好救下女主 |
| 反派升级攻击，是因为**主角上一集的反击威胁到了他的核心利益** | 反派突然变得更坏，因为"剧情到了该升级的时候" |

### 角色决策检验三问

对每个重大转折，回答：

1. **谁做的决定？**——必须是具体角色，不能是"命运"、"巧合"、"剧情"
2. **他/她为什么现在做？**——必须有本集内的触发原因，不能是"一直想但恰好现在做了"
3. **他/她为此付出了什么？**——每个决策必须有可见的代价或风险

### 决策-后果链示例

```
女主决定揭露仇人
  ↓ 为什么现在？
  因为她刚发现仇人下一个目标是她的家人
  ↓ 她付出了什么？
  她自己的身份暴露，与霸总的信任关系破裂
  ↓ 后果是什么？
  仇人提前发动攻击，女主陷入孤立无援
  ↓ 她的下一个决策？
  在失去一切的情况下，独自应战
```

## 五、利害关系递增（Escalating Stakes）

每一幕（约 5 集为一个戏剧单元）的利害关系必须比前一幕更高。不能出现"第五集赌上性命，第十集为面子吵架"的倒挂。

### 利害层级定义

| 层级 | 利害类型 | 示例 | 适用阶段 |
|------|---------|------|---------|
| L1 | 社交/面子 | 被人看不起、丢了面子、被孤立 | 前 3 集 |
| L2 | 机会/资源 | 失去工作、丢掉合约、资金断裂 | 第 3-7 集 |
| L3 | 关系/情感 | 信任崩塌、盟友背叛、爱人离去 | 第 7-12 集 |
| L4 | 自由/地位 | 被陷害入狱、身份被剥夺、众叛亲离 | 第 12-16 集 |
| L5 | 生命/终极 | 生命威胁、至亲存亡、终极一战 | 第 16-20 集 |

### 利害递增检验

```
| 集数范围    | 本阶段最高利害层级 | 是否高于前一阶段 | 递增证据（哪个具体事件体现） |
|------------|-----------------|-----------------|-------------------------|
| 第 1-5 集   | L1/L2           | —               |                         |
| 第 6-10 集  | L2/L3           | ✓ / ✗           |                         |
| 第 11-15 集 | L3/L4           | ✓ / ✗           |                         |
| 第 16-20 集 | L4/L5           | ✓ / ✗           |                         |
```

**铁律**：如果利害关系没有递增，必须重写——不是加更多敌人，而是让代价更个人化、更不可逆。

## 六、场景级因果——每场戏的"为什么现在"和"有什么不同"

一场戏就是一个因果单元。每场戏必须回答两个问题。

### 场景因果卡（每场戏填写）

| 字段 | 定义 | 检验 |
|------|------|------|
| **为什么现在** | 为什么这场戏必须发生在此时而非之前或之后 | 如果挪到前一场或后一场，剧情逻辑是否断裂？ |
| **有什么不同** | 这场戏结束后，哪个状态发生了不可逆的改变 | 如果去掉这场戏，后续哪场戏会因此不成立？ |
| **入场状态** | 角色带着什么情绪/目标/信息进入 | 角色想要什么？ |
| **出场状态** | 角色带着什么情绪/目标/信息离开 | 和入场相比，什么被永久改变了？ |

### 场景因果链图示

```
场景 A（女主被羞辱）
  为什么现在：这是女主第一次公开露面，羞辱必须发生在公众场合
  有什么不同：霸总看到了她，女配的仇恨从暗转明
  ↓
场景 B（霸总出手）
  为什么现在：因为场景 A 刚结束，霸总的信息是热乎的，干预必须即时
  有什么不同：女主的处境从孤立变成有靠山但更危险
  ↓
场景 C（女配密谋）
  为什么现在：因为场景 B 霸总的出手直接威胁到女配的地位
  有什么不同：女配从暗中使绊升级为主动策划攻击
```

## 七、反 AI 模式——禁止清单

以下 AI 写作中的常见病态模式，出现即为错误。

| 禁止模式 | 问题本质 | 错误示例 | 正确做法 |
|---------|---------|---------|---------|
| **"突然"无因** | 事件缺乏可见前因 | "突然，一道闪电劈中了古树" | 必须有前 1-2 场的铺垫：天气恶化→雷声渐近→闪电劈下 |
| **降神解法** | 用外部力量化解角色困境 | "危急时刻，一位从未提过的高手从天而降" | 主角用自己的能力/人脉/智慧脱困，或此前已埋下援军伏笔 |
| **万能道具** | 用事先未提及的道具解决一切 | "幸好我随身带了祖传的解药" | 道具必须在前情中出现过且建立其限制条件 |
| **信息差滥用** | 靠角色不沟通制造虚假冲突 | "我本想解释，但转身走了"×5 次 | 沟通失败必须有角色性格/处境/利害关系的深层原因 |
| **巧合连环** | 连续使用巧合推进剧情 | 恰好遇到+恰好听到+恰好拿到 | 见第三节巧合预算规则 |
| **情绪归零** | 重大事件后角色情绪像没发生过 | 上一集母亲去世，下一集嬉笑打闹 | 角色情绪必须有持续性和转化过程 |

### "突然"审计

全文搜索"突然"、"忽然"、"恰好"、"正好"——每一处必须能回答"为什么此刻"并且有前情铺垫，否则标记为因果断裂。

## 八、验证清单（每集大纲完成后必须执行）

### A. 单集因果检查

- [ ] 本集每个核心事件是否都有可识别的前因？
- [ ] 每个核心事件是否都产生了不可逆的后果（关系/信息/权力/风险/目标至少一项改变）？
- [ ] 每个核心事件是否都有角色反应（情感判断 + 行为决策）？
- [ ] 本集的结尾是否是下一集的原因或障碍（"因此"或"但是"，不是"然后"）？
- [ ] 本集是否使用了巧合？如有，是否登记、计额度、只制造麻烦？

### B. 全剧因果链检查（规划阶段完成后）

- [ ] 从高潮到激励事件能否完成完整回溯，每个节点因果成立？
- [ ] 巧合总数是否 ≤ 全剧集数/5？
- [ ] 所有巧合是否只制造麻烦而没有解决问题？
- [ ] 所有重大转折是否由角色主动决策驱动而非外部事件？
- [ ] 利害关系是否逐幕递增（L1→L5），未曾倒挂？
- [ ] 是否存在"突然"无因、降神解法、万能道具、信息差滥用？

### C. 场景因果检查（写作阶段每场戏）

- [ ] 这场戏"为什么现在"——能否给出具体原因？
- [ ] 这场戏"有什么不同"——入场/出场状态是否明显改变？
- [ ] 去掉这场戏，后续剧情是否会因此断裂？如果不会，这场戏是否必要？

### D. 最终审查（审读阶段）

- [ ] 全文"突然/忽然/恰好/正好"审计完成，每处有因果铺垫？
- [ ] 高潮解决方式是否来自角色能力/成长/关系积累而非外力降神？
- [ ] 全剧是否存在"情节推着角色走"的被动感？
- [ ] 情绪 K 线图是否与因果链一致——情绪高点是否对应因果积累的自然释放？

## 九、常见因果病与修复方法

| 病症 | 症状 | 根因 | 修复方法 |
|------|------|------|---------|
| **悬浮反转** | 反转惊天动地但回想起来毫无铺垫 | 反转只有"果"没有"因" | 向前 2-3 集插入伏笔——不是明示，是让观众事后回想"原来如此" |
| **情绪透支** | 前期冲突太猛，后期无事可写 | 利害关系一开始就拉满 | 重新分级利害——前 5 集降级到 L1/L2，为后期留空间 |
| **机械因果** | A→B→C 过于平滑，毫无意外 | 只有"因此"没有"但是" | 在关键节点插入角色误判/信息不完整/对手出乎意料的行为 |
| **因果断崖** | 两个阶段之间没有因果连接，像换了一部剧 | 阶段转换用"然后"而非"因此/但是" | 找到前一阶段的"未完成事件"，让它成为下一阶段的导火索 |
| **主角旁观** | 主角在关键事件中只是目击者而非推动者 | 决策缺位 | 修改事件，让主角的选择成为事件的必要条件——没有这个选择，事件不会发生 |

## 十、与现有 Skill 的协同

| 配合 Skill | 协同方式 |
|-----------|---------|
| `script-episode-planner` | 集间衔接的"因此/但是/然后"规则与本 Skill 因果链直接对应——分集规划时必须同步执行因果验证 |
| `script-cliffhanger` | 悬念必须来自本集因果链的自然延伸，不能是外部贴附的噱头 |
| `script-review` | 审读阶段的连续性检查需使用本 Skill 的场景因果卡和因果回溯表 |
| `script-cn-short-drama` | 短剧单集闭环规则与场景"有什么不同"检验互为约束 |
| `script-character-depth` | 角色决策驱动力需要角色有明确的欲望、恐惧和缺陷——深度越高的角色，其决策的因果性越强 |

---

**核心原则**：好的短剧剧情，是观众看完后能说出"因为 A 所以 B，但是 C，因此 D"——而不是"然后 A，然后 B，然后 C"。
