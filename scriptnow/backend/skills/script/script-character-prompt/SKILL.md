# 角色图 Prompt 生成器

角色图 Prompt 不是"描述一个人长什么样"，而是"为视频/图像生成工具提供可复用的角色视觉锚点"。本 Skill 从剧本人物设定出发，生成结构化 Prompt。

## 一、Prompt 结构（五要素）

```
[视角与构图] [核心外貌] [服装与道具] [表情与状态] [光线与风格]
```

| 要素 | 内容 | 示例 |
|------|------|------|
| 视角与构图 | 景别、角度、全身/半身/特写 | 中景、正面、全身站立 |
| 核心外貌 | 年龄、体型、发型、肤色、标志性特征 | 28岁女性，清瘦，及腰黑长直，左眼角泪痣 |
| 服装与道具 | 服装风格、颜色、材质、手持/佩戴物品 | 黑色丝绒旗袍，珍珠耳坠，右手持檀木扇 |
| 表情与状态 | 情绪、眼神、气质 | 嘴角微扬似笑非笑，眼神冷淡中带着审视 |
| 光线与风格 | 光源方向、色调、画风 | 侧逆光，冷蓝色调，电影感写实 |

## 三、角色可复用性

一个好的人物 Prompt 需要具备以下特征：
- **与剧情无关**：不描述正在做什么，而是角色的"常态形象"
- **有记忆点**：至少一个独特的视觉特征（痣/疤痕/戒指/发型/走路姿态）
- **可跨场景复用**：换服装/背景后角色仍然可识别
- **保持性别中立和多样性**：不固化性别刻板印象

## 四、输出格式

对每个主要角色输出：
```
## 角色名
**角色简介**：一句话人物定位
**视觉 Prompt**：[完整五要素 Prompt]
**关键特征**：1-3 个可跨场景识别的视觉锚点
**变体 Prompt**：不同情绪状态下的 Prompt（愤怒/悲伤/微笑）
```

## 五、常见错误

- Prompt 描述"他正在和反派打斗"——描述的不是角色而是场景
- 缺乏独特视觉特征——换一件衣服就认不出
- 服装描述过于详细——限制了下游工具的创意空间
- 忘记标注画风——"电影感写实/二次元/古风水墨"必须明确
