# 短剧角色鲜活度

竖屏短剧最大的质量杀手是类型化脸谱——复仇者只有恨、霸总只有冷、灰姑娘只有惨。真实的人在任何处境下都有矛盾、有私密的温柔、有不被故事主线捕捉的习惯。本Skill强制每个角色拥有超出"情节功能"的鲜活维度。

## 一、矛盾特质（每个主角至少一对）

人物最让人记住的不是优点或缺点，是矛盾：
- 复仇者可能在深夜给流浪猫喂食，但从不承认自己养猫
- 霸总可能对数字极度敏感却在记人名上有障碍，桌上永远贴着员工照片+名字的便签
- 灰姑娘可能在财务上极度精明——她穷但从不借贷，有一本精确到分的账本

**矛盾不削弱人设，而是让人设可信。**

定义规则：
- 矛盾必须与核心设定产生摩擦但不推翻——它让人物有纹理，不是让人物分裂
- 矛盾必须至少在一个场景中成为情节的支点（阻碍/助力/揭示）
- 禁止"表面冷酷内心温柔"的通用模板——矛盾必须具体到行为

## 二、私密习惯（每个主角至少一个）

人物在不被观察时的习惯是他们唯一真实的时刻：
- 特定情境下的重复动作：紧张时拆笔、等人时数地砖、撒谎时摸耳后
- 私人仪式：每天早上第一件事是擦桌子、每次打完电话会把手机翻过来放
- 物品依赖：必须随身携带的物件、绝不允许别人碰的东西

用法：在关键情绪场景中，让这个习惯成为情绪的信号——习惯的中断或强化比台词更有力。

## 三、隐性欲望（与显性目标区分）

| 显性目标（角色说的） | 隐性欲望（角色不承认的） |
|---------------------|------------------------|
| "我要报仇" | 想被那个伤害过的人亲口说一句"对不起" |
| "我要夺回属于我的一切" | 想证明离开的人当初看错了 |
| "我不需要任何人" | 害怕再次被抛弃所以抢先拒绝 |

隐性欲望的揭示规则：
- 不能由角色自述——必须通过行为或他人视角揭示
- 至少在全剧中段（约第 10 集）有一次"隐性欲望被触及"的时刻——角色差点承认但退缩，或有人戳穿了但角色否认
- 终局时隐性欲望必须有一个明确的终点——满足/放弃/转化为新的欲望，不能悬置

## 四、关系特异性行为

同一角色在不同关系中必须有差异化表现：
- 对上司/长辈：他是顺从还是暗顶？用什么方式隐藏真实态度？
- 对下属/晚辈：他是苛刻还是放任？训人时用什么词？夸人时是否别扭？
- 对爱人/挚友：他卸下防备的瞬间是什么样？他最怕对方问什么问题？
- 对敌人：他尊重对手还是蔑视？复仇方式是否暴露了他对敌人的"在意"？

**强关系戏的黄金规则**：两个角色独处一室，他们对彼此的了解必须不对等——A 知道 B 的某个秘密/B 不知道 A 已经知道了/两个人都以为对方不知道其实互相知道——这种认知差产生最精彩的对白。

## 五、人物出场规则

每个重要角色首次出场必须包含：
1. 一个 **身份标识**（视觉/声音/动作，区别于其他角色）
2. 一个 **态度信号**（对当前事件的第一反应，直接展示性格）
3. 一个 **潜在疑问**（让观众产生"他为什么这样"）

禁止出场方式：简历式介绍（"他是XX集团总裁，32岁，海归"）→ 信息通过行为和对白自然散落。

## 六、人物自检清单

每个角色创建后：
- [ ] 遮住名字描述这个角色，能与其他角色区分吗？
- [ ] TA 的缺点是否在某个场景中真正阻碍了 TA 的目标？（没阻碍的缺点是标签，不是缺点）
- [ ] TA 有没有一个不服务于主线的私人时刻？（有这个时刻才算活着）
- [ ] TA 和至少两个其他角色之间存在不对等的认知差吗？
- [ ] 如果删掉 TA 最亲密的关系，TA 还是同一个角色吗？（如果是，说明关系不够深）
