# 小说 → 竖屏短剧改编

改编的本质是"带着镣铐跳舞"：忠于原著精神内核，重构为短剧节奏语言。本 Skill 覆盖从小说素材分析到分集大纲产出的全流程，不涉及分镜写作（交给 `script-cn-short-drama`）。

## 前置条件

- 小说素材已完成 `novel-source-distiller` 或 `script-source-distiller` 分析，持有可引用的候选项目档案
- 目标集数、单集时长已明确（默认 1-2 分钟/集）
- 改编方向已确认：忠实改编 / 框架改编 / 灵感改编

---

## 一、素材分析阶段（只读，不写）

从已蒸馏的小说素材中提取改编所需全部关键信息，只做结构化分析，不产出可写入脚本的内容。

### 1.1 核心要素提取

| 维度 | 提取内容 | 产出格式 |
|------|---------|---------|
| 主线冲突 | 核心矛盾（身份/阶级/情感/生存）、升级路径、解决方式 | 冲突弧线图（起→承→转→合） |
| 人物关系图谱 | 关系类型（敌对/同盟/摇摆/隐藏）、权力动态、情感强度 | 关系矩阵 + 关键变化节点 |
| 关键反转节点 | 身份揭露、权力逆转、真相曝光、情感转折 | 反转时间轴（位置 + 力度评分 1-5） |
| 结局方向 | 结局类型（HE/BE/OE）、情感落点、未解伏笔 | 结局摘要 + 改编可用性评估 |
| 经典对白/场景 | 可保留的"名场面"和原文对白 | 引用库（标注原著章节位置） |

### 1.2 商业卖点识别

从原著中识别并标注以下卖点密度与短剧适配性（高/中/低）：

- **情感关系类**：虐恋拉扯、先婚后爱、破镜重圆、替身文学
- **身份反转类**：隐藏身份揭露、逆袭打脸、扮猪吃虎
- **复仇爽点类**：委屈积蓄→当众反击、连环报复
- **强设定类**：穿越重生、系统金手指、契约婚姻、信息差碾压

### 1.3 情节分级

对所有情节单元做三级分类，生成"情节地图"标注因果依赖：

- **🔴 必须保留**：核心冲突起承转合节点、人物质变场景、名场面
- **🟡 可合并/压缩**：功能重复的情节、过渡性场景、氛围渲染
- **⚫ 可删减**：配角支线、纯风景/心理描写、可被一个镜头替代的铺陈

## 二、改编蓝图阶段（产出可审阅的大纲）

基于素材分析生成结构化改编蓝图，产出物是审阅材料而非最终分镜。

### 2.1 故事大纲重构

- **世界设定简化**：保留拍摄可呈现的设定，删除需大量特效/文字解释的部分；复杂规则系统压缩为 1-2 句口头交代
- **人物精简**：保留核心 3-5 人，其余角色功能合并到保留人物上
- **主冲突提炼**：从多线冲突中提取最有视觉冲击力和情感张力的那一条作为主线，其余降级为背景

### 2.2 人物弧线映射

为每个保留角色建立"原著→短剧"对照：

```
角色：XXX
原著成长线：起点状态 → 关键转折1 → 关键转折2 → 终局状态
短剧情绪弧：压抑 → 小释放 → 再压抑 → 大释放 → 升华
保留场景：必须出现的原著场景（最少 3 个，与弧线节点对应）
删减/合并：配角关系或次要成长线处理方式
```

### 2.3 关键反转时间点适配

将原著反转节点按短剧节奏（每 1-2 分钟一个节拍）重新排布：

| 原著反转 | 原著位置 | 短剧集数 | 适配方式 | 情绪方向 |
|---------|---------|---------|---------|---------|
| 反转名称 | 章/百分比 | 第 N 集 | 提前/延后/拆分/合并 | 压抑→释放 |

---

## 三、分集拆分阶段

将改编蓝图拆分为逐集大纲，每集是独立的"情绪单元 + 悬念单元"。

### 3.1 拆分规则

- 每集必有：**开场钩子 → 情绪推进 → 集末悬念**
- 关键情节不可被集数边界切断：完整的"压抑-释放"循环归于同一集
- 原著伏笔优先转化为集末悬念：结尾落在"观众想知道接下来会怎样"的时刻

### 3.2 每集大纲模板

```
第 N 集：{集标题}
- 开场钩子（0-5 秒落地）：从原著哪段高潮/冲突提取，直接切入
- 本集爽点/冲突：原著情节来源 + 短剧化处理方式
- 保留对白：名场面原句保留，普通对白缩编为核心信息
- 集末悬念（最后 5-10 秒）：落在未解问题/反转预告上
- 情绪曲线：压弹簧 / 放弹簧 / 过渡呼吸
```

### 3.3 跨集衔接检查

- 相邻两集悬念连贯（上集末钩子在下集开头被兑现或推进）
- 连续压抑不超过 3 集（参考 `script-cn-short-drama` 情绪弹簧规则）
- 每集独立可看（新观众从任意一集进入都能快速理解冲突）

---

## 四、改编原则

1. **先保故事，再改形式**：不以凑集数拆分关键情节，一个情绪循环即一集
2. **原著伏笔优先转化为集末悬念**：短剧"追更"机制天然适配多层伏笔——每一层伏笔揭开都是天然钩子
3. **人物关系保持原著核心动态**：删配角不改变主角间权力关系和情感流向；合并配角时确保关键功能被承接
4. **对白保留"名场面"级原句**：经典对白是整季记忆点；普通对白压缩为核心信息量，砍掉修饰铺垫

---

## 五、常见改编陷阱

| 陷阱 | 表现 | 对策 |
|------|------|------|
| 照搬小说章节结构 | 按原著章节对应短剧集数，节奏拖沓或密度不均 | 瓦解章节边界，以"情绪单元"为拆分单位 |
| 删太多导致不连贯 | 砍掉过多过渡情节，观众无法理解动机变化 | 每次删除后追问：下一段的因果关系还成立吗？ |
| 加太多原创内容 | 为迎合竖屏套路添加与原著精神相悖的内容 | 新增只允许两种：填补因果缺口、将抽象转为可拍行为 |
| 忘记每集是独立情绪单元 | 集末落在日常对话或场景过渡，无悬念钩子 | 每集大纲最后一步：如果这是第一集，观众想看下一集吗？ |
| 忽略改编方向差异 | 用忠实改编方法做灵感改编，或反之 | 开始前锁定方向：忠实改编不新增核心情节，灵感改编只保精神内核 |
