# Apply a screenplay structure

1. Read the selected structure from CreativeProfile; never silently substitute another method.
2. Use the matching method exposed by the core `script-storymap` skill.
3. Map every required function to an observable Story Beat and completion condition.
4. For short-form work, merge beats only when every merged function remains explicit.
5. Promote cross-scene discoveries through a CreativeChangeProposal instead of silently changing canon.
6. For structure changes, return beat mapping, affected scenes, risks and unmapped accepted material.
