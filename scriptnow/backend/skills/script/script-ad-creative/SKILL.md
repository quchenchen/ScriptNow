# 短剧投流素材生成器

投流素材不是"把剧集剪一段发出去"，而是"在 3 秒内让目标受众停下来，在 15 秒内让他们想点进来"。本 Skill 从剧本中提取可测试的广告素材。

## 一、投流素材三段式

| 阶段 | 时长 | 目标 | 内容来源 |
|------|------|------|---------|
| 钩子 | 0-3 秒 | 停下滑动 | 剧本中最具冲击力的画面/台词/冲突 |
| 卖点展开 | 3-12 秒 | 建立追剧欲望 | 身份揭露、关系张力、复仇爽感的浓缩版 |
| CTA | 最后 3 秒 | 引导点击 | 明确的行动指令+紧迫感 |

## 二、六种投流钩子类型

| 类型 | 机制 | 剧本提取点 | 适用题材 |
|------|------|----------|---------|
| **身份揭露钩** | 隐藏身份被揭穿的瞬间 | 主角亮身份/令牌/信物的场景 | 男频逆袭、战神 |
| **关系张力钩** | 感情关系的关键对峙 | "你为什么要骗我？""因为我爱你。" | 女频甜虐、霸总 |
| **打脸爽感钩** | 被羞辱后的反向碾压 | 势利眼前任当众被打脸 | 复仇、逆袭 |
| **悬念提问钩** | 抛出一个必须知道答案的问题 | "你以为那场火灾是意外？" | 复仇、悬疑 |
| **变身视觉钩** | 超自然力量的视觉冲击 | 月圆变身/狼化特征的展现 | 狼人 |
| **保护宣言钩** | 角色为保护某人而宣言 | "他是我的人，谁敢动？" | 霸总、战神 |

## 三、卖点脚本模板

```
【开场钩子】[从剧本中提取的 3 秒冲击画面]
【一句话卖点】[整部剧最核心的一句话卖点]
【身份/关系/冲突】[2-3 句话展开核心看点]
【爽点预告】[1-2 个具体爽点场景的预告]
【CTA】"点击观看全集，看他如何[核心期待]"
```

### 示例——战神归来：
```
【开场钩子】黑西装律师站在垃圾场对拾荒者说：林先生，您继承的资产已生效。
【一句话卖点】被退婚的穷小子，真实身份是万亿财阀唯一继承人。
【身份/关系/冲突】前女友家族当众羞辱他，却不知他手中握着能让他们倾家荡产的筹码。
【爽点预告】公开打脸势利眼前任、碾压商界对手、揭开母亲被害真相。
【CTA】点击观看全集，看他如何从垃圾场走向财阀之巅。
```

## 四、多版本测试策略

一次生成 3 个变体，测试不同钩子类型的效果：

```
变体 A（身份揭露钩）：侧重"他到底是谁"的好奇心
变体 B（打脸爽感钩）：侧重"看他怎么反击"的爽感预期
变体 C（情感张力钩）：侧重"他和她还能在一起吗"的情感驱动
```

每个变体使用相同的卖点脚本结构但不同的开场钩子。

## 五、分题材投流策略

| 题材 | 最有效钩子 | 目标受众话术 |
|------|----------|------------|
| 复仇 | 打脸爽感钩 | "看她如何让背叛者跪下" |
| 女频甜虐 | 关系张力钩 | "他爱她，但他不能说" |
| 男频逆袭 | 身份揭露钩 | "所有人都以为他是废物，直到那天..." |
| 霸总 | 保护宣言钩 | "全世界的规则对他无效，只有她例外" |
| 战神 | 身份揭露钩+保护宣言钩 | "他脱下战甲只为守护一个人" |
| 狼人 | 变身视觉钩 | "月圆之夜，他体内的野兽觉醒了" |

## 六、常见错误

- 钩子画面不是剧本里最好看的一帧而是最刺激的一帧
- CTA 太笼统——"点击观看"不如"点击看他如何反击"
- 卖点信息过载——3 个清晰的看点优于 10 个模糊的
- 忘记标注测试变体——不测试等于用猜的
