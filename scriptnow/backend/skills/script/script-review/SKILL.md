# 剧本审读

## 审读原则

1. 先审戏剧，再审格式。
2. 证据驱动：每条发现必须锚定场次/block + 引用原文 + 违反准则 + 影响 + 最小修复方向。
3. 分层判定：blocking > major > minor > craft > taste。

---

## 一、视听语言审查

### 1.1 小说式心理描写（blocking）

action 块中出现以下模式，直接判定 blocking：

| 关键词/模式 | 问题 |
|------------|------|
| 心想、心中、内心、心里 | 不可拍摄的心理活动 |
| 感到、感觉、觉得 | 主观感受陈述 |
| 回忆、想起、浮现、思绪 | 不可拍摄的回忆触发 |
| 情绪、心情、心态 | 不可拍摄的抽象状态 |
| 意识、意识到 | 不可拍摄的认知变化 |

### 1.2 身体隐喻式动作（major）

用身体部位做情绪隐喻——小说修辞，不是剧本动作。

| 模式 | 示例 |
|------|------|
| 手指/骨节/指尖 + 形容词 | 「骨节发白」「指尖泛白」 |
| 指甲/掌心 + 动词 | 「指甲掐进掌心」 |
| 喉头/喉咙 + 动词 | 「喉头发紧」 |

### 1.3 触觉嗅觉描写（major）

音像作品只能传达视觉和听觉。触觉、嗅觉、温度感不可拍摄，出现在 action 中判定 major。

| 禁用模式 | 示例 |
|---------|------|
| 温度触觉 | 温温的、发麻、冰凉、刺痛、柔软、粗糙、滚烫 |
| 嗅觉 | 闻到、气味、香味、臭味、刺鼻 |
| 体感 | 震得指尖发麻、皮肤发凉、背脊发寒 |

```
❌ 「木轴温温的，震得指尖发麻」
   → major: 温度（温温的）+ 触觉（发麻）= 都不可拍摄

✅ 修正：「她把手从木轴上抽回来。甩了甩。」
   → 摄影机看到：动作+结果。触觉通过动作表达。
```

### 1.4 抽象氛围概括（major）

| 禁用词 | 为什么 |
|--------|--------|
| 气氛紧张/凝固/压抑 | 没写「谁做了什么导致气氛改变」 |
| 命运、宿命、人生、时光、岁月 | 概念词，不是视听信息 |
| 精致、优雅、奢华、华丽、简陋 | 美术概括，需给出具体视觉元素 |

### 1.5 机械悬念句（major）

```
❌ 「他不知道，更大的风暴还在后面等着他。」
❌ 「殊不知，这一切只是开始。」
```
直接删除，不替换。

### 1.6 情绪宣告式对白（major）

```
❌ 「我恨你！」「你为什么要这样对我！」
   没有伴随当场可见的后果——判定 major。
```

## 二、戏剧性审查（新增）

这是解决「白描有余、戏感不足」的核心维度。

### 2.1 无事件场景（blocking）

读完一场戏，如果回答「这场戏发生了什么事」只能是「有人在某个地方，氛围怎样怎样」——blocking。

```
❌ 「清晨，她坐在纺织机前。木轴转着。车间里光线昏暗。」
   → blocking: 白描环境+状态，没有事件。什么都没有发生。
```

判定标准：场景中是否有人做了动作，导致局面发生可观察的变化。

### 2.2 缺乏冲突（major）

场景中有目标方但没有抵抗方——或抵抗方是「命运」「社会」等抽象概念——判定 major。

```
✅ 冲突：她想签下订单。继母先一步通知客户工厂倒闭了。
❌ 冲突：她想要成功。命运在阻挠她。
```

### 2.3 缺乏升级（major）

场景中冲突原地踏步——同一层级反复但没有加码——判定 major。

升级可以是：新信息入场、新人物介入、已有威胁兑现、选择空间被压缩。

### 2.4 缺乏转折（blocking）

场景结束时，权力/关系/信息/风险与开场时完全一致——blocking。

### 2.5 缺乏后果（major）

转折发生了但没有为下一场种下压力或新选择——major。

## 三、对白七维审查

### 1. 角色辨识度（blocking）
遮住角色名，能否凭语气/用词/节奏认出说话人？

### 2. 潜台词（major）
表层文字与里层意图是否分层？直白解释剧情/情绪是 major。

### 3. 冲突推进力（major）
这句是否改变了目标/权力/关系/信息/风险至少一项？

### 4. 类型语感（major）
古装混入网络梗、都市整段文言——越界即 major。

### 5. 信息效率（major）
exposition 灌设定、电报式碎片堆叠——major。

## 四、竖屏短剧专项

- slugline 符合「场-镜 地点·细地点 时间 内/外」
- 关键分镜用 ▲ 或 ▲【…】，常规画面不用
- 场景开头有「人物：×××、×××」
- 【特写】【闪回】成对
- 画面描述 20-30 字
