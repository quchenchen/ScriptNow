# 圆桌会诊参考（详细版）

> 方法论参考：《剧本训练》蔡导 Skill 3「剧本医生·圆桌会诊」与 Skill 1 多视角审稿步骤，本文按 ScriptNow 体系重写。

## 四视角评估要点

### 编剧视角
- 单场唯一功能：删掉本场是否改变因果/关系/信息边界？不变则重写或合并。
- 每场必须发生可观察转折：目标/权力/关系/知识/风险至少一项改变。
- 角色选择必须付出代价；好人好事/坏人坏事的模板化是 major。

### 制片视角
- 场景是否可低成本拍摄（竖屏短剧优先室内/小场景）？
- 台词是否给演员留了可演空间（语气注、动作、停顿）？
- 特效/群演/外景密度是否超预算？

### 观众视角
- 前 3 秒钩子是否成立；中段峰值是否够爽/够虐；结尾卡点是否让人想点下一集。
- 有没有"读者会划走"的段落（连续 30 秒无变化/信息/情绪）。
- 人物是否值得站队（有欲望、有软肋、有代价）。

### 平台视角
- 题材与平台调性匹配度；红线风险（审核）。
- 付费卡点是否自然（每集 1-2 个），而非硬切。
- 完播/追更逻辑：下一集的钩子是否埋在前一集结尾。

## 反捧杀示例

❌ "整体完成度很高，四视角一致通过，只有个别台词可以润色。"
✅ "编剧视角有一个结构问题：第 3 集结尾的钩子是新增威胁，但与前两集的主冲突没有因果衔接，观众会感到被硬拉进度。建议把钩子改为前两集铺垫的伏笔兑现。"

## 优先级排序规则

1. 因果/连续性破坏（必改）
2. 付费卡点缺失或硬切（必改）
3. 台词无角色辨识度（必改）
4. 可拍性/成本风险（建议改）
5. 类型语感漂移（建议改）
