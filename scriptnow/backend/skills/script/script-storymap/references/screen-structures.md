# Screen structures

Use only the structure requested in the CreativeProfile. Treat every beat as a change in goal, plan, stakes, relationship, knowledge, or self-understanding. Short-form work may merge beats, but must preserve their dramatic function.

## Hero's Journey (`hero-journey`)

Ordinary world → call → refusal → mentor → threshold → tests/allies/enemies → ordeal → reward → road back → resurrection → return. Externalize every stage as a filmable decision; omit mythic labels from the screenplay itself.

## Three Act (`three-act`)

Act I establishes the dramatic contract and ends with an irreversible commitment. Act II escalates strategies, reverses understanding at midpoint, and ends in crisis. Act III converts the crisis into a final choice, climax, and changed image.

## Five Act (`five-act`)

Introduction → rising action → climax → falling action → resolution. The climax is the irreversible dramatic peak; falling action must show consequences rather than repeat the climax.

## Save the Cat (`save-the-cat`)

Opening image, theme stated, setup, catalyst, debate, break into two, B story, promise of premise, midpoint, pressure closes in, all is lost, dark night, break into three, finale, final image. Page ratios are diagnostics, not mandatory timestamps.

## Eight Sequence (`eight-sequence`)

Build eight sequences with a local question, active objective, escalating opposition, sequence climax, and handoff consequence. For short work, pair sequences while preserving each question and turn.

## Harmon Circle (`harmon-circle`)

Comfort → need → unfamiliar situation → adaptation → obtain desire → pay a price → return → changed state. Make the price and change observable through action.

## Freytag Pyramid (`freytag`)

Exposition → rising action → climax → falling action → denouement. Use primarily when consequences after the climax materially complete the dramatic argument.

## Custom (`custom`)

Require named stages, order, target proportion, completion condition, mandatory turns, and permitted compression. Reject a custom structure that merely renames an existing method without defining different behavior.
