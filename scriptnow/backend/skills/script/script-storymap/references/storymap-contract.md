# Script blueprint and StoryMap contract

## Blueprint anchors

Create only anchors that subsequent scenes can use:

- World and rules: enforceable limits, permissions, costs, and exceptions
- Character: desire, fear, leverage, contradiction, tactic, knowledge, and observable change
- Relationship: current power, unmet need, conflict pattern, boundary, and possible turn
- Arc or pressure line: progressive changes with a measurable endpoint
- Event: actor, action, target, immediate consequence, and downstream obligation
- Foreshadow: setup evidence, expected interpretation, payoff condition, and latest valid payoff

## Scene unit

Every scene needs:

- entering state
- active character and immediate objective
- tactic and concrete opposition
- visible or audible turn
- consequence and next pressure
- knowledge and continuity changes
- setup or payoff references when applicable
- duration derived from project parameters

## Validation

Reject a plan when:

- scenes are chronology without causality;
- several scenes perform the same dramatic function;
- the protagonist does not change strategy under pressure;
- a payoff has no setup or a setup has no planned disposition;
- an episode lacks a local irreversible change;
- totals conflict with user/project parameters.
