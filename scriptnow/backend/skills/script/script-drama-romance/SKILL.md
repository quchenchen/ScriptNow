# 女频甜虐短剧 craft

甜虐的本质是"越靠近越危险，越远离越想念"。继承 `script-cn-short-drama` 的全局规则，本 Skill 定义女频关系驱动的专属叙事机制。

## 一、关系五段弧线

| 阶段 | 核心事件 | 情绪方向 |
|------|---------|---------|
| 误会/分离 | 因外部压力或信息差被迫分开 | 压（虐） |
| 命运重逢 | 不可抗拒的命运让两人再次相遇 | 小放 |
| 试探/拉扯 | 彼此试探真心，在靠近与远离之间反复 | 压放交替 |
| 真相揭露 | 当年的误会/阴谋大白于天下 | 大放 |
| 双向奔赴/虐心回收 | 经历考验后的重新选择 | 回收放 |

## 二、情绪弹簧以关系变化为核心

- **亲近 = 放**：告白、保护、为对方破例、公开承认关系
- **疏远 = 压**：误会加深、第三者介入、家族施压、一方被迫离开
- **"追妻火葬场"节奏**：前期男主冷漠/伤害 → 中期女主觉醒离开 → 后期男主追悔挽回——这是女频最强付费点弧线

## 三、人设张力法则

**男主人设**：表面冷漠/强势/掌控，内在有软肋（过去的伤痕/对女主的例外）
- 对所有人都冷酷，只对女主破例：这是付费核心
- "口是心非"是甜虐的基本功：嘴上说不在意，行动上拼了命

**女主人设**：从被动接受到主动掌控关系
- 第 1-5 集：被动承受/隐忍
- 第 6-12 集：觉醒/开始反击或主动离开
- 第 13-20 集：掌控关系主动权，让对方追

## 四、付费卡点（关系关键时刻）

- 表白即将说出口的前一刻被意外打断
- 误会即将澄清时，新证据让误会更深的瞬间
- 女主决定离开，男主追到机场/车站的最后一秒悬念
- 身份真相（契约/假结婚/隐藏身份）被踢爆前一刻

## 五、常见误用

- 男主"霸道"变成"不尊重"——霸道是保护欲，不是控制欲
- 女主"傻白甜"无成长弧线——必须有觉醒时刻
- 每集同一模式拉扯（反复分手和好）导致审美疲劳
- 忘记甜的成分——虐是为了让甜更甜，不是纯粹虐心
