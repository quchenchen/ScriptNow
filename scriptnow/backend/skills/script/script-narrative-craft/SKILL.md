# 叙事手艺：信息、节奏与工具选择

## 为什么需要这份指南

AI 已经能做到「每一句都是可拍摄的」——但能做到和知道该拍什么是两回事。

当前的核心问题不是技法层面的「怎么写」，而是判断层面的「写什么」和「用什么写」：
- 无法判断哪些信息是核心戏点
- 对所有细节一视同仁，导致失焦
- 用动作堆砌回避对话，导致信息模糊

这份指南解决的就是这三个问题。

---

## 一、信息层次：不是所有信息都值得被写出来

### 每场戏只设一个核心信息

在开始写任何一场戏之前，回答：

**「这场戏里，观众只需要记住哪一件事？」**

如果答案是两件或更多——拆成两场或更多。

```
✅ 八零后妈 5-1 的核心信息：
   司念揭穿刘婶的真实目的。

✅ 无双 2-1 的核心信息：
   楚青能调动南省最大的权力人物。

✅ 花繁叶茂 1-1 的核心信息：
   唐万财的儿子考上大学了——他的骄傲和焦虑都在这一件事上。
```

### 三层信息模型

把每场戏的信息分为三层：

| 层次 | 定义 | 工具 | 篇幅 |
|------|------|------|------|
| **核心** | 观众必须记住的一件事 | 对话 | 一句或一组对话，最长不超过本场的 30% |
| **支撑** | 帮助观众理解核心的上下文 | 对话 + 动作 | 铺垫、解释、对比 |
| **氛围** | 环境/情绪/节奏 | 动作 | 一两个即可，不展开 |

```
❌ AI 常犯的层次混淆：

△ 清晨的阳光透过斑驳的窗棂洒进来。（氛围→展开成完整句子）
△ 她坐在床边，被角起了毛边。（氛围→展开）
△ 桌上的茶凉了。窗外鸟叫了三声。（氛围→展开）
△ 「该走了。」（核心——淹没在氛围细节中）

→ 核心只有三个字，氛围写了四行。观众已经被细节塞满，
  根本注意不到「该走了」。

✅ 正确的层次：

△ 茶凉了。她没再续。（氛围——一行，快速带过）
△ 她把存折推过桌面。
   「你的。」
   他盯着存折。没拿。「我不要钱。」
   「我知道。」
△ 门关上了。（支撑——动作验证后果）

→ 核心清晰：「她用存折做了一件事，他拒绝了。」
   氛围不抢戏，支撑紧贴核心。
```

### 写完后的删减测试

1. 遮住所有动作，只读对话——故事还成立吗？
2. 如果不成立，说明核心信息被放在了动作里，需要移到对话中。
3. 如果成立，再读一遍动作——哪些删掉不影响理解？删掉。

## 二、工具选择：对话、动作、沉默

### 三个工具，三种功能

```
对话 = 精确传达信息
       角色通过语言：宣告、试探、威胁、承诺、揭露、拒绝

动作 = 验证或推翻对话
       角色通过行为：靠近还是远离、拿起还是放下、快还是慢

沉默 = 放大张力
       角色通过不做什么、不说什么——让观众自己填补
```

### 工具选择矩阵

| 你要传达什么 | 首选工具 | 为什么 |
|------------|---------|--------|
| 角色做了一个决定 | 对话 | 决定需要被说出来才能被验证 |
| 角色在骗人 | 对话（说谎）+ 动作（露馅） | 对话建立谎言，动作拆穿 |
| 角色感到悲伤但没有说 | 动作 | 动作比台词诚实 |
| 角色在犹豫 | 沉默 + 一个微小的动作 | 沉默是最好的犹豫 |
| 角色之间的关系变了 | 对话摆出新位置 + 动作验证 | 角色说「以后我们是陌生人了」→ 下一个动作是转身但没走 |
| 环境的氛围 | 动作——一两个即可 | 不要展开，氛围是背景不是前景 |
| 过去的创伤 | 对话——从冲突中漏出来 | 不单独回忆，让角色在吵架/辩解/威胁时带出 |

### 什么时候绝对不要用动作

当以下信息需要被传达时，**必须用对话**——动作不可能替代：

1. **角色的决定**：「我要走了」「我不签」「我嫁」——这需要被说出来，因为说出来本身就构成了行动。
2. **关系的重新定义**：「从今天起，你不再是我哥」「我们结束了」——宣布本身改变了关系。
3. **权力的宣告或挑战**：「三分钟，南省除名」「你自己的人，自己管好」——权力在话语中实现。
4. **秘密的揭露**：「他早就知道了」「那孩子是你的」——秘密的内容只能用对话传达。

## 三、叙事节奏：铺垫与核心的比例

### 铺垫是蓄力，核心是释放

观众在铺垫阶段的注意力是在等待——等待那个反击、那个翻转、那个真相。
铺垫可以展开，因为观众的期待在积累。但铺垫不能喧宾夺主。

```
正确的铺垫结构：

对手/环境施加压力（铺垫）→ 压力积累 → 主角反击（核心）→ 验证后果

✅ 八零后妈 5-1：
   刘婶赶人（压力）+ 大娘帮腔（压力积累）+ 局势恶化（压力顶峰）
   → 司念一句话揭穿（核心反击）→ 刘婶慌乱（验证）

✅ 无双 2-1：
   周麒炫耀靠山（压力）+ 手下附和（压力积累）+ 威胁升级（压力顶峰）
   → 楚青打电话（核心反击）→ 任城森到场（验证）
```

### 比例检查

```
铺垫篇幅 : 核心篇幅

✅ 6:1 ~ 8:2 → 合理。铺垫充分，核心锐利。
❌ 1:1 → 失败。铺垫和核心同等重量 = 无重心。
❌ 10+:1 → 失败。铺垫过长，观众等不耐烦。
```

## 四、「电影感」陷阱

### AI 对「高级叙事」的误解

AI 经常试图用一连串动作、道具、环境细节去暗示一个核心信息，
以为这是「电影感」和「高级叙事」。这不是。

真正的电影叙事中，核心信息仍然通过对话和戏剧行动传达。
动作和环境的「暗示」服务于氛围、情绪、潜台词——但不取代核心信息的交付。

```
❌ AI 的「电影感」：
   她用一连串动作暗示她决定离开——收拾、看照片、摸门框、
   看窗外的树、走到门口、回头——但一个字没说。
   → 这不是电影感。这是模糊。

✅ 真正的电影感：
   「我走了。」她把钥匙放在桌上。
   门关上了。他盯着那把钥匙。
   钥匙在桌上。他坐在椅子上。没动。
   → 核心信息用对话交付。然后沉默和动作放大后果。
```

### 记住

**信息用对话。氛围用动作。张力用沉默。**
三个工具各司其职，不要用一个替代另一个。
