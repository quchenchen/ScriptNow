# 中文竖屏短剧 craft

竖屏短剧不是传统剧集的缩水版：观众以 1-2 分钟为单位决策是否继续，每一集都必须是一个完整的"情绪单元"。所有规则用于指导性建议，不做硬性裁决。

## 一、情绪弹簧（全局节奏）

- 每集要么"压弹簧"（积蓄期待/压抑），要么"放弹簧"（兑现爽感/反转），不存在中间状态。
- 每 1-2 集必须有一个情绪释放点；连续压抑不超过 3 集，防止情绪疲劳。
- 大爆发前必有大压抑：最爽的"打脸"之前先让主角受最大的委屈，反差越大爽感越强。
- 安排短暂的"呼吸感"场景作为节奏调节器，为下一次爆发蓄力。
- 整季可以看作一张"情绪 K 线图"：压抑低谷与释放峰值交错，峰值逐步抬高。

## 二、单集闭环（1-2 分钟/集）

| 时段 | 功能 |
|---|---|
| 0-5 秒 | 开篇钩子：危机、身份揭露或情感冲突，让观众停下滑动 |
| 中段（30-45 秒） | 本集情绪峰值：小反转/小高潮，压到极致或放到极致 |
| 结尾（最后 5-10 秒） | 再钩子：更强悬念或未完成动作，落在付费卡点 |

示例节奏：前男友带新女友出现（钩子）→ 嘲讽与隐忍（压）→ 身份揭露（放）→ 留下"再见"抛新钩子（卡点）。

## 三、台词法则

- **信息前置**：第一句话抛身份/冲突/目标，不绕弯子；一句话说完绝不用两句。
- **消灭废话**：删除"你好吗""最近怎么样"式闲聊；每句台词必须推动情节或塑造人物。
- **潜台词动作化**：把角色的潜台词变成可拍的行为，不靠内心独白解释。

## 四、短剧五维自检（写作与评审共用）

1. **核心爽点**：普世（对应大众普遍渴望/压抑）、具体可拍（"当众打脸势利眼"优于"成功"）、递进（小爽点 2-3 集一次 / 中爽点约 10 集一次 / 大爽点关键节点）。
2. **故事类型**：强设定（隐藏身份、特殊能力、特殊关系、特殊环境）+ 经典模式带创新。
3. **人物设定**：人设是"容器"——一个鲜明标签 + 可被剧情反复挤压的欲望/软肋。
4. **人物关系**：关系变化驱动剧情（误会、拉扯、反转），不是背景板。
5. **情节桥段**：桥段可复用但必须换皮换情，避免审美疲劳。

## 五、常见误用

- 每集节奏相同（全是压或全是放）导致套路化
- 钩子无铺垫或结尾钩子与正文无关
- 台词文学化绕弯，信息密度不足
- 连续压抑超过 3 集没有释放，观众流失
- 为了卡点硬切，转折缺乏因果
