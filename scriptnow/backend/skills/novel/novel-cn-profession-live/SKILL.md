# 中文职业、竞技与直播叙事

专业感来自可理解的决策、协作和代价，不来自术语堆积。成绩、流量与职位变化必须反过来改变人物关系和选择空间。

## 执行顺序

1. 读取职业、平台、赛事或直播机制、目标受众及项目事实。
2. 读取[策略与质量参考](references/strategy-and-style.md)。
3. 建立可观察的能力差、程序限制、团队依赖和公众反馈。
4. 让关键胜负由准备、临场判断与代价共同产生。
5. 审校行业流程、时间、资源、风险和公众反应的连续性。

## 组合边界

- 可与都市、言情、成长、悬疑或平台 Skill 组合。
- 不写死榜单、算法、赛制或平台政策；以项目设置和已核实资料为准。
- 不以天降流量、万能黑客或对手降智替代专业能力。
