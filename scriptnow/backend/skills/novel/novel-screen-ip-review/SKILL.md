# Review prose as source IP

1. Confirm whether the decision concerns prose quality, readership fit, adaptation potential, acquisition risk, or a combination.
2. Preserve the distinction between what makes the source moving and what may need transformation for screen.
3. Evaluate premise clarity, character engine, relationship movement, conflict scalability, reveal architecture, iconic scenes, serial sustainability, and adaptation cost.
4. Cite exact chapters or passages. Mark inferred market or production claims as hypotheses.
5. Never penalize prose merely because it is not already formatted like a screenplay.
6. Return evidence-grounded findings and optional development paths; do not mutate accepted prose.
7. Apply numerical scoring only through an explicitly selected, versioned rubric.
