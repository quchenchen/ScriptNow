# Plan a novel

1. Load accepted premise, canon, unresolved constraints, and target length.
2. Define the ending state first: external outcome, inner transformation, thematic answer, and irreversible price.
3. Build the causal spine from inciting disruption through escalating commitments, midpoint reframe, collapse, final choice, and aftermath.
4. Give every major character a desire, fear, strategy, contradiction, change pressure, and observable endpoint.
5. Create chapter units with viewpoint, goal, obstacle, turn, consequence, continuity inputs, and hook. A chapter without a state change must be merged or redesigned.
6. Run continuity and pacing checks before proposing the blueprint candidate.

For beat selection, read [story structures](references/story-structures.md) only for the requested structure.
