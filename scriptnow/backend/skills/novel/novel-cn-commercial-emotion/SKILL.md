# 中文商业情绪与关系推进

强情绪来自信息、选择和关系后果的连续升级，不来自重复羞辱或让人物失去判断力。

## 执行顺序

1. 读取目标平台、受众、篇幅参数、关系边界、已采纳事实和最新人工修订。
2. 读取[策略与质量参考](references/strategy-and-style.md)，明确本轮的情绪承诺。
3. 为主角建立欲望、防御、底线、行动能力和不可逆代价。
4. 用信息差、公开选择和关系重估推动升级；非关键过渡可以压缩。
5. 审校区分“高压冲突”“重复受虐”和“胁迫被浪漫化”。

## 组合边界

- 可与现代言情、都市、职场、重生及平台 Skill 组合。
- 爽点比例与节奏密度来自项目参数或评测策略，不在 Skill 中写死。
- 不复制外部爆款事件链，不以羞辱弱者或消除退出权制造廉价快感。
