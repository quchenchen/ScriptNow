# 伏笔网络管理

伏笔不是"前面提一句后面用上"，而是一个需要刻意设计的三阶段系统。本Skill确保每个伏笔有布设、有暗示、有回收，且回收时刻让读者感受到"本该如此"而非"莫名其妙"。

## 一、伏笔三阶段生命周期

### 阶段 1：布设（Plant）
布设时伏笔必须满足：
- **融入叙事**：伏笔在首次出现时不能以"这很重要"的方式呈现，必须伪装成普通叙事元素
- **多义性**：布设时的信息允许至少两种解读——一种表面解读，一种真相解读
- **记录规则**：每条伏笔必须记录：布设位置（集/章）、布设形式（对话/描写/动作/物件）、表面含义、隐藏含义、预计回收位置
- 禁止"旁白宣告"式伏笔：不写"他不知道这个决定将改变一切"

### 阶段 2：暗示（Signal）
在回收前，伏笔需要至少一次暗示：
- 暗示不揭示真相，但让细心读者感到"这里有点奇怪"
- 暗示距离：小伏笔（10 集内回收）暗示放在回收前 2-3 集；大伏笔（全季回收）暗示放在回收前 10-15 集
- 暗示形式应与布设形式不同——如果布设是对话中的一句话，暗示可以是物件再次出现或配角反应异常
- 回收前的"最后暗示"：让读者即将猜到但还差一步——"就差一点"

### 阶段 3：回收（Payoff）
回收时刻的质量标准：
- **意外但合理**：读者事先没想到，但回头翻前面会发现所有线索都在
- **因果闭合**：回收解释了布设时的"不对劲"，且不留逻辑漏洞
- **情感重量**：回收不是信息通报，而是伴随角色的情感反应——惊讶/释然/后悔/恐惧
- **连锁反应**：重大伏笔回收后必须产生至少一个后续影响（改变关系/改变目标/改变认知）

## 二、伏笔类型与密度

| 类型 | 回收跨度 | 密度（每集/章） | 示例 |
|------|---------|----------------|------|
| 物件伏笔 | 1-5 集 | 0.5-1 个 | 一把钥匙、一张照片、一个疤痕 |
| 对话伏笔 | 2-10 集 | 1-2 个 | 角色说漏嘴的一句话、一个回避的问题 |
| 行为伏笔 | 3-15 集 | 0.5-1 个 | 角色特定的恐惧反应、重复的异常行为 |
| 身份伏笔 | 5-全季 | 0.2-0.5 个 | 某角色的真实身份/动机/过去 |

禁止同时布设超过 3 个未回收的大伏笔——超过 3 个读者会忘记。

## 三、伏笔追踪表

每个项目维护以下追踪（由 Agent 通过工具查询）：
- 已布设未回收的伏笔列表
- 每条伏笔的当前状态：planted / signaled / payoff-ready
- 距离预计回收位置还有多少集/章
- 是否有伏笔超过预计回收位置仍未回收（列为 overdue）

## 四、回收检查

每次写新章节/集时：
1. 检查是否有 overdue 伏笔——如果有，本单元必须回收至少 1 个
2. 检查是否有 payoff-ready 伏笔——如果本单元的情绪场景恰好匹配，优先回收
3. 新布设的伏笔必须记录，且大伏笔需预分配回收位置

## 五、禁止的"假回收"

以下模式视为未回收：
- 回收时增加新信息而非揭示已有线索 → 这是新布设，不是回收
- 角色"突然想起"之前的事情 → 这是倒叙说明，不是伏笔回收
- 用旁白或画外音解释"原来当初那个……" → 让读者自己发现，不要替读者解读
- 回收后没有任何角色因此改变行为或认知 → 回收无意义
